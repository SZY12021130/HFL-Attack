# 同态加密 × 联邦学习：模式总结、演进链剖析与五方案设计（UAV/边缘场景）

> **范围**：`paperlist/` 目录下 11 篇与"同态加密 + 联邦学习（HE+FL）"直接相关的 PDF（17-SecAgg ~ 26-PPBR）。
> **视角**：RLWE/CKKS 派密码 × 联邦学习系统结构 × 无人机/边缘辅助层次联邦学习。
> **目标**：
> 1. 总结 11 篇方案的模式（单密钥/多密钥/阈值；标准 FL/层次 FL；有无可信机构）；
> 2. 推理出"问题 → 方案 → 新缺陷 → 新方案"的循序渐进演进链；
> 3. 梳理 UAV（UAV-Assist / Edge-Assist）场景下 FL 的真实挑战与值得研究的点；
> 4. 在此基础上构建 **5 个结构与逻辑上优于本目录最新研究的方案（2 个标准 FL 架构 + 3 个层次型 FL 架构）**，每个方案给出实体、威胁模型、符号系统、闭环 RLWE 公式推导、时序图与安全性分析证明。

## 1.2 四个分类维度

### 维度一：密钥范式（谁持有什么，能解密什么）

| 范式 | 代表 | 优点 | 缺点 |
|---|---|---|---|
| **掩码 + 秘密共享**（明文域） | P1 SecAgg | 通信轻、抗掉线好 | 服务器只见一次"和"，无法做密文域加权/裁剪；$O(n^2)$ 协商 |
| **单密钥 HE**（打包 CKKS/BFV/Paillier） | P5 ESAFL、P6 FedPHE、P8 SKHE、P10 DSVFL | 密文体积小、聚合便宜、客户端计算轻 | 需 KDC/TA/TEE 作信任锚；单点妥协全库解密 |
| **多密钥 HE**（MK-CKKS/BFV） | P2 CDKS、P4 SecFed、P7 MASER、P9 CDKS-LSS | 无 TTP，各方私钥自持 | 部分解密份额泄露；密文体积/计算随参与方数膨胀 |
| **HE + Shamir 混合** | P8、P9、P10、P11 | 抗掉线 + 抗合谋 + 可阈值 | 系统复杂度上升，份额通信不可忽视 |

### 维度二：架构（几层、聚合几级、权重怎么算）

- **标准 FL（端-云 / 客户端-参数服务器）**：P1、P2、P3、P4、P5、P6、P7、P9、P10 —— 一级聚合，服务器做（加权）平均。
- **层次 FL（端-边-云 / 端-UAV-云）**：P8（云-边-端 IoT）、P11（移动边缘端-边-云）。**两级聚合**：边缘先聚合一辖区，云再聚合全局；权重分两层算（簇内平均 → 簇间平均）。
- **与密码正交的通信优化**：P3 ResFed（残差预测压缩），可叠加到任何架构。

### 维度三：可信机构（有/无、在线/离线、信任强度）

| 信任锚类型 | 方案 | 评价 |
|---|---|---|
| 无 TTP（纯密码保证） | P2 CDKS、P7 MASER、P9 CDKS-LSS | 最干净，但 P7 仍要可信 Key Manager 做 setup |
| 依赖 TEE | P4 SecFed、P8 SKHE | 信任收缩到硬件，UAV 端难部署、侧信道风险 |
| 依赖 KDC/TA | P6 FedPHE、P10 DSVFL、P8 SKHE（TA） | 长期在线假设在跨域 UAV 协同下不现实 |
| 初始化一次性可信方（之后离线） | P5 ESAFL（AS） | 折中：setup 后无在线 TTP，但初始化窗口是攻击面 |
| 半诚实边服务器 | P11 PPBR | 边被物理俘获（UAV 场景高发）即全边层失守 |

### 维度四：安全目标（隐私 / 可验证 / 鲁棒 / 抗掉线）

| 目标 | 现有覆盖 | 空白 |
|---|---|---|
| 服务器不见单个更新 | 全部（除 P3） | — |
| 抗客户端掉线 | P1、P4、P5、P8、P9、P10、P11 | MKHE 路线（P2、P7）基本无 |
| 抗客户端合谋 | P1、P5、P6、P8、P9 | 多数方案仅半诚实 |
| **抗服务器作恶（可验证）** | **仅 P10**（签名链） | 最大空白：服务器可篡改聚合而无人发现 |
| 抗拜占庭恶意更新 | 仅 P11（CLDP+边层过滤） | 与 HE 结合几乎空白 |
| 抗半可信边缘 | P8（TEE 兜底）、P11（PLHE 单密钥托管在边） | 边层密钥分片缺失 |

## 1.3 循序渐进：演进链（问题 → 方案 → 新缺陷）

HE+FL 的主线是"**如何在不可信聚合者面前安全地算出模型更新的（加权）和**"。每一步都解决上一步的痛点，同时暴露新的痛点。

```
阶段0  明文 FedAvg
       └─ 缺陷：服务器直接看到每个 w_i，可被梯度反演恢复训练数据
阶段1  P1 SecAgg (2017)：DH 两两掩码 + 自掩码 + Shamir 分享
       └─ 解决：单服务器安全聚合，任意子集掉线可去掩码
       └─ 新缺陷：① O(n²) 客户端通信；② 只能求和，无法密文域加权/裁剪/验证；
                  ③ 服务器仍可能串通客户端后单独"摘除"某诚实方掩码
阶段2  P2 CDKS / MK-CKKS (2019)：各方独立密钥，密文域可加可乘
       └─ 解决：不共享密钥也能跨用户密文运算，支持外包推理
       └─ 新缺陷：① 分布式解密要求各方上传部分解密值 μ_i = c_i·s_i，
                    服务器已知 c_{i,0}，于是 c_{i,0}+μ_i ≈ m_i —— 个体更新直接泄露；
                  ② 计算/密文随参与方数 O(k²) 膨胀
阶段3  P4 SecFed (2024)：多密钥 BFV 拆进 TEE，TEE 生成补充密文
       └─ 解决：MKHE 抗掉线（TEE 补密文）、重线性化/噪声刷新卸载
       └─ 新缺陷：信任锚换成 TEE 硬件；不防投毒；GP-TEE 交互开销大
阶段4  P7 MASER (2025, xMK-CKKS)：共识剪枝 + slicing 把 MKHE 开销压下来
       └─ 解决：MKHE 密文体积/计算逼近明文 FedAvg 的 1.48–5×
       └─ 新缺陷：① partial decryption 仍在，服务器（合谋下）仍可反推个体更新；
                  ② 要求所有客户端在线做部分解密 —— 不防掉线；
                  ③ 依赖可信 Key Manager
阶段5  P9 CDKS-LSS (2026)：把 μ_i 在环 R_q 上再做 (t,n)-Shamir
       └─ 解决：① 部分解密泄露被堵死（服务器只见聚合份额的插值结果）；
                ② 阈值解密，t-out-of-n 抗掉线；③ 无 TTP、后量子
       └─ 新缺陷：① 参与方两两 P2P 交换 R_q 元素份额，每轮百 MB 级；
                  ② 假设服务器半诚实，不验证服务器是否篡改聚合；
                  ③ 无拜占庭鲁棒
阶段6  P5 ESAFL (2025, 并行支线)：多密钥加密、单聚合密钥 ESHE 解密
       └─ 解决：彻底绕开"份额分发/部分解密"问题 —— 密文相加即为聚合，
                只有一个聚合解密密钥 s = Σ s_i 能解，效率逼近单密钥
       └─ 新缺陷：① s 的初始化/分发依赖可信 AS（或 MPC），密钥分发问题只是搬了家；
                  ② 仅加法同态；③ 未显式处理掉线
阶段7  P8 SKHE / P11 PPBR (2025-26)：进入层次型架构
       └─ 解决：云-边-端/端-边-云两级聚合；PPBR 首次统一隐私 + 拜占庭鲁棒
       └─ 新缺陷：P8 靠 TA+TEE；P11 的 PLHE 单密钥托管在单一边服务器，
                  边被俘获即全边层解密；均无密钥分片、无可验证聚合
阶段8  P10 DSVFL (2026)：Paillier + Shamir + 签名链，聚合可验证
       └─ 解决：服务器聚合结果可被客户端验证，抗掉线
       └─ 新缺陷：Paillier 非 RLWE（大模型下密文巨大）、强 TA、标准架构
```

**主线一句话**：SecAgg 用掩码藏"和" → CDKS 把"和"算进密文但解密份额泄露 → xMK-CKKS（MASER）压住效率但仍有份额泄露且不防掉线 → CDKS-LSS 用 LSS 堵泄露并实现阈值 → ESAFL 干脆消灭份额分发但引入初始化信任锚。**份额的安全性与分发的便利性是这对矛盾的主轴**；架构侧则从端-云推进到端-边-云（P8/P11），可信侧在"无 TTP / TEE / KDC / 一次性 AS"之间反复摇摆。

## 1.4 UAV / Edge-Assist 场景：挑战与值得研究的点

### 1.4.1 物理与链路约束（决定方案可行性的硬数字）

| 约束 | 量级 | 对方案设计的含义 |
|---|---|---|
| UAV 巡航速度 | 10–30 m/s | 簇成员/簇头/地面站连接关系每轮都可能变 |
| 空地链路 | 间歇遮挡、多径、雨衰，丢包率高、时延抖动大 | 不能假设"所有客户端在线"；协议必须 $t$-out-of-$n$ |
| 机载能量 | 电池决定计算+通信预算 | 客户端只应做轻量 RLWE 加密/份额生成；MKHE 重线性化、Bootstrapping、$O(n^2)$ P2P 协商都要避免 |
| 机载算力 | 远低于云 | 阈值解密份额、承诺证明等重活应卸载给边缘/云 |
| 覆盖临时性 | 客户端随 UAV 移动换边 | 密钥/份额不能绑定固定参与者，需动态再分配 |
| 数据异构 | 不同空域 Non-IID | 拜占庭更新与正常 Non-IID 更新难区分 |

### 1.4.2 安全层面的挑战

1. **半诚实假设不够**：UAV/边缘节点物理暴露在野外，被俘获/被仿冒概率远高于云机房；现有方案大多默认半诚实。
2. **空域攻击面**：GPS 欺骗、Sybil、MITM、Jamming。需要认证信道、抗 Sybil 身份绑定、可验证聚合。
3. **带宽-模数链两难**：CKKS 模数链越深密文越大；UAV 链路每 bit 都贵，密文不能膨胀 → 稀疏化/打包/残差编码必须与 HE 联合设计。
4. **无 TTP**：跨域/跨国 UAV 协同不适合常驻 TA；KDC 长期在线假设几乎不成立。

### 1.4.3 值得研究的点（→ 五个方案的问题空间）

| # | 研究点 | 现状缺口 | 对应新方案 |
|---|---|---|---|
| R1 | 无 TTP 下抗掉线的阈值多密钥解密，且堵住部分解密泄露 | P9 解决泄露但 P2P 份额通信大、假设服务器半诚实 | 方案一 |
| R2 | 无 TTP/无 TEE 的密钥生成（DKG）+ 密文域聚合 + straggler 规避 | P5 需 AS、P6 需 KDC、P7 需 Key Manager | 方案二 |
| R3 | 半可信边缘 + 拜占庭 UAV + 云阈值解密的层次架构 | P11 单密钥托管在边、P8 依赖 TEE | 方案三 |
| R4 | 高移动拓扑下的动态密钥再分配（簇头可换、密钥不变） | 所有现有方案密钥绑定固定参与者 | 方案四 |
| R5 | 稀缺 UAV-云链路上的带宽友好跨域层次聚合 | P3/P6 与 HE 未联合；P11 无跨 silo 设计 | 方案五 |

# 第二部分　五个新方案

> **总体设计原则**（五个方案共同遵守）：
> 1. 密码原语统一为 **RLWE/CKKS 系**（与 P2/P5/P7/P9 同族，后量子、可打包浮点）；
> 2. 客户端（UAV/移动端）只承担**采样 + 一次 RLWE 加密 + 可选份额生成**，重活（插值重构、验证、承诺证明）卸载给边缘/云；
> 3. 每个方案明确给出**合谋上限、掉线容忍、可信实体清单**——安全性质只在威胁模型内宣称；
> 4. 每个方案都针对 1.4 节某个具体研究点 R1–R5，且在结构上严格优于对应最新论文（下文每方案 5.3 节逐条论证）。

五个方案速览：

| 方案 | 名称 | 架构 | 密钥模式 | 信任锚 | 解决的核心缺口 |
|---|---|---|---|---|---|
| 一 | **TVF-MKCKKS**：可验证阈值多密钥 CKKS | 标准 FL | 多密钥 + $R_q$ LSS 阈值 | 无 TTP/TEE | R1：服务器作恶可被发现 + 抗掉线 + 无 P2P 份额直连 |
| 二 | **JZD-FL**：联合 DKG 零和掩码加性 RLWE | 标准 FL / cross-silo | 联合公钥 + $(t,n)$ 阈值 | 无 TTP/TEE | R2：密钥生成去 TTP + straggler 选择 + 密文膨胀控制 |
| 三 | **UEC-BR**：UAV-Edge-Cloud 层次 CKKS + 边缘拜占庭过滤 + 云阈值解密 | 层次 FL | 云密钥 $(t,l)$ 分片在边缘 | 离线 KGA（可替换为 DKG） | R3：半可信边缘 + 拜占庭 UAV + 云轻量验证 |

## 方案一　TVF-MKCKKS：可验证阈值多密钥 CKKS 联邦学习（标准 FL 架构）

> **定位**：研究点 R1。目标：在**无 TTP、无 TEE** 的前提下，同时做到 ① 服务器看不到任何单个更新；② 部分解密份额不泄露（优于 P2/P7）；③ $t$-out-of-$n$ 抗掉线（优于 P2/P4/P7）；④ **服务器篡改聚合可被客户端以高概率发现**（补齐 P9 与 P10 之间最关键的缺口——P9 无验证、P10 非 RLWE 且需强 TA）。

### 5.1 场景

多架 UAV（数十至数百架）组成侦察/搜救编队，每架在本地训练轻量目标检测模型，通过**不可信地面站 GS**（参数服务器）聚合。空地链路间歇，每轮只有部分 UAV 能完成交互；GS 位于任务区域，**可能好奇、也可能主动作恶**（替换某架 UAV 的密文、谎报聚合结果、选择性丢弃诚实份额）。要求：

- GS 不能看到任何单个 UAV 的更新（隐私）；
- 任意 $<t$ 个 UAV 与 GS 合谋仍推不出诚实 UAV 的更新（抗合谋）；
- 只要 $\ge t$ 个 UAV 完成份额阶段，本轮即可解密（抗掉线）；
- GS 若篡改任何一个密文/份额/聚合结果，诚实验证者能以 $\ge 1-\epsilon$ 的概率发现（**可验证**，现有 MKHE 方案均不具备）；
- 不依赖 TTP、TEE、KDC。

### 5.2 要解决的问题（与最新研究的差距）

| 现有方案 | 已解决 | 未解决（本方案补齐） |
|---|---|---|
| P9 CDKS-LSS（本目录最新 MKHE 阈值方案） | 部分解密泄露、$t$-out-of-$n$、无 TTP | ① 服务器被默认为**半诚实**，篡改聚合无人发现；② 参与方两两 P2P 交换 $R_q$ 份额，每轮百 MB 级，UAV 间歇链路扛不住 |
| P7 MASER / xMK-CKKS | MKHE 效率 | 无掉线容忍、partial decryption 仍泄露、需可信 Key Manager |
| P1 SecAgg | 抗掉线安全聚合 | 不支持密文域运算；服务器作恶无验证 |
| P10 DSVFL | 聚合可验证 | Paillier 非 RLWE 且密文巨大、强 TA、标准架构 |

**核心差距**：把"CDKS-LSS 的 LSS 阈值解密"与"服务器辅助的加密份额转发 + RLWE 同态承诺链"结合起来——份额不再走 UAV↔UAV 直连，而是经 GS 以 pairwise 会话密钥加密转发（GS 只见密文份额）；同时为每轮聚合附上 RLWE 同态承诺，任何客户端可用 Fiat-Shamir 抽查验证 GS 没有替换任何人的密文。

### 5.3 创新点 / 总体设计目标

1. **无 TTP 的阈值多密钥 CKKS**：每架 UAV 自持 RLWE 密钥对，全局解密能力以 $R_q$ 上 $(t,n)$-Shamir 分散在全体 UAV 的部分解密份额中。
2. **服务器辅助的加密份额转发（SA-assisted share forwarding）**：用一次性 DH 协商的会话密钥加密份额、GS 转发，替代 P9 的 P2P 份额直连——UAV 只需维护与 GS 的单跳链路，适配间歇空地链路。
3. **RLWE 同态承诺 + 客户端抽查验证**：每个 UAV 对自己的密文分量发布承诺，承诺对加法同态，GS 必须为聚合结果给出"承诺打开一致性"证明；诚实客户端抽查使 GS 篡改被发现的概率可参数化到任意接近 1。
4. **严格优于 P9**：安全性上多出恶意服务器检测能力；通信上 P2P 份额流量转为经服务器的密文转发（单跳、可重传）；功能上支持密文域加权（CKKS 打包天然支持）。

### 5.4 威胁模型

- **地面站 GS**：**主动恶意（malicious）**——可窃听、重放、替换/丢弃/伪造密文与份额、谎报聚合结果；可与 $<t$ 个 UAV 合谋。
- **UAV 客户端**：半诚实（诚实但好奇）；合谋数 $<t$（含与 GS 合谋）。
- **外部敌手**：可监听 GS↔UAV 公共信道；不能攻破 RLWE（决策性 RLWE 假设）、AEAD 认证加密与抗碰撞哈希。
- **合谋上限**：$\le t-1$ 方与 GS 合谋 ⟹ 无法重构任何诚实 UAV 的个体更新，也无法伪造一个能通过抽查的错误聚合。
- **掉线容忍**：每轮任意 $n-t$ 个 UAV 在份额阶段掉线；密文已上传但份额阶段掉线者，其更新仍参与聚合（份额已由存活方持有）。
- **可信实体**：无在线 TTP/TEE/KDC；仅公开 CRS（或每轮公开 PRG 种子生成 $a$）；假设存在认证信道（UAV 预置证书/PKI 抗 Sybil）。

### 5.6 方案设计：实体交互与闭环公式推导

**实体**：UAV 集合 $\mathcal{U}=\{U_1,\dots,U_n\}$；地面站 GS。

#### 5.6.1 Setup（集群组成变化时执行，非每轮）

1. 每架 $U_i$ 本地采样 RLWE 密钥：
$$s_i\leftarrow\chi_s,\quad e_i\leftarrow\chi_e,\quad b_i=-a\,s_i+e_i\pmod q,\quad pk_i=(b_i,a).$$
$pk_i$ 连同身份签名广播、经 GS 转发给全员；$sk_i=s_i$ 本地保存。
2. **一次性 pairwise 会话密钥**（仅用于份额转发）：$U_i$ 生成临时 DH 对 $(x_i,g^{x_i})$，广播 $g^{x_i}$；与 $U_j$ 共享 $\sigma_{ij}=g^{x_ix_j}$，$k_{ij}=\textsf{KDF}(\sigma_{ij}\|i\|j)$。攻击窗口仅限集群重组时刻，且份额本身还有 LSS 保护（双保险，见 5.8）。

#### 5.6.2 第 $r$ 轮训练

**步骤 1（本地训练与多密钥加密）**。$U_i$ 得更新 $w_i$，编码缩放 $m_i=\Delta\cdot\textsf{Ecd}(w_i)\in R_q$。采样 $v_i\leftarrow\chi_s$，$e_{i,0},e_{i,1}\leftarrow\chi_e$，计算 RLWE 密文：
$$
\begin{aligned}
c_{i,0}&=v_i\,b_i+m_i+e_{i,0}\pmod q,\\
c_{i,1}&=v_i\,a+e_{i,1}\pmod q.
\end{aligned}
$$
正确性展开（单密钥相位，CDKS 的基础单元）：
$$
c_{i,0}+c_{i,1}s_i=v_i(b_i+as_i)+m_i+e_{i,0}+e_{i,1}s_i=m_i+\underbrace{v_ie_i+e_{i,0}+e_{i,1}s_i}_{\text{小噪声 }E_i}\approx m_i\pmod q.
$$
$U_i\to GS$：$\theta_i=(c_{i,0},c_{i,1})$、签名 $\sigma_i=\textsf{Sign}_{i}(c_{i,0},c_{i,1},r)$、密文哈希 $h_i=H(\theta_i)$。

**步骤 2（GS 密文聚合）**。GS 对存活集合 $\mathcal{U}_{\text{live}}$ 验签后做分量加法：
$$
c_0=\sum_{i\in\mathcal{U}_{\text{live}}}c_{i,0}\pmod q,\qquad \mathbf{ct}=\bigl(c_0,\ \{c_{i,1}\}_{i\in\mathcal{U}_{\text{live}}}\bigr).
$$
多密钥相位（CDKS 聚合密文对所有参与私钥同时满足）：
$$
c_0+\sum_{i\in\mathcal{U}_{\text{live}}}c_{i,1}\,s_i=\sum_i m_i+\sum_i E_i\approx\Delta\sum_i\textsf{Ecd}(w_i)\pmod q. \tag{1}
$$

**步骤 3（RLWE 同态承诺，验证之锚）**。每个 $U_i$ 在步骤 1 同时采样 $r_i\leftarrow\chi_s$，发布承诺：
$$
\textsf{Com}_i=\bigl(c_{i,1},\; c_{i,0}+a\,r_i\bigr)\ \in R_q^2,
$$
并向 GS 发送 $\gamma_i=a\,r_i$（盲化项，可随密文同发）。承诺的加法同态性：
$$
\sum_{i}\textsf{Com}_i=\Bigl(\sum_i c_{i,1},\; c_0+\textstyle\sum_i\gamma_i\Bigr)=:\textsf{Com}_{\text{agg}},
$$
即"密文分量之和 ↔ 承诺分量之和"严格对齐。**GS 之后若替换任何一个 $\theta_i$，则 $\sum c_{i,1}$ 不变但 $c_0$ 变，导致 $\textsf{Com}_{\text{agg}}$ 的第二分量对不上**——这是检测的代数基础（5.8 证明其 soundness）。
$GS\to$ 所有 $U_j$：广播 $\{h_i\}$、$\{\gamma_i\}$、$\mathcal{U}_{\text{live}}$。

**步骤 4（部分解密与 LSS 分享——本方案隐私核心）**。每架 $U_i$ 从 GS 取回聚合密文的"自己那一支" $c_{i,1}$（GS 本就持有），计算部分解密并加大噪声淹没：
$$
\mu_i=c_{i,1}\,s_i+e_i^{\text{pd}}\pmod q,\quad e_i^{\text{pd}}\leftarrow\chi_e^{\text{pd}}.
$$
若直接把 $\mu_i$ 给 GS，则 GS 用 $c_{i,0}+\mu_i\approx m_i$ 恢复个体更新（P2 的漏洞）。故 $U_i$ 在 $R_q$ 上采样随机 $t-1$ 次多项式 $f_i(X)=f_{i,0}+f_{i,1}X+\dots+f_{i,t-1}X^{t-1}$，令 $f_i(0)=\mu_i$，计算全部份额 $\tilde\mu_{i,j}=f_i(\alpha_j)$，用会话密钥封装：
$$
e_{i,j}=\textsf{AEAD}_{k_{ij}}\bigl(\tilde\mu_{i,j}\,\|\, j\,\|\, r\,\|\, \textsf{MAC}\bigr),\qquad U_i\to GS:\ \{e_{i,j}\}_{j\in\mathcal{U}}.
$$

**步骤 5（GS 转发 + UAV 本地份额聚合）**。GS 把 $e_{i,j}$ 路由给 $U_j$（只见密文）。$U_j$ 解密得 $\{\tilde\mu_{i,j}\}_{i}$，只对 $\mathcal{U}_{\text{live}}$ 中的加密者求和：
$$
\tilde\mu_j=\sum_{i\in\mathcal{U}_{\text{live}}}\tilde\mu_{i,j}=\Bigl(\sum_i f_i\Bigr)(\alpha_j)=:F(\alpha_j)\pmod q,
$$
其中 $F(X)=\sum_i f_i(X)$ 仍是 $\deg\le t-1$ 多项式且
$$
F(0)=\sum_i\mu_i. \tag{2}
$$
$U_j\to GS$：$\tilde\mu_j$（附签名）。

**步骤 6（GS 阈值重构与全局解密）**。GS 收集任意 $T\subseteq\mathcal{U}_{\text{live}}$、$|T|\ge t$ 个聚合份额，Lagrange 插值重构：
$$
\mu^{*}=\sum_{j\in T}\lambda_j^{(T)}\,\tilde\mu_j=\sum_{i\in\mathcal{U}_{\text{live}}}\mu_i\pmod q,\qquad
\lambda_j^{(T)}=\prod_{k\in T,k\ne j}\frac{\alpha_k}{\alpha_k-\alpha_j}\in R_q.
$$
结合式 (1)(2)：
$$
M=c_0+\mu^{*}=\Delta\sum_i\textsf{Ecd}(w_i)+\underbrace{\textstyle\sum_i(E_i+e_i^{\text{pd}})}_{\text{可控噪声}}\pmod q,
$$
$$
w_G=\frac{1}{|\mathcal{U}_{\text{live}}|}\cdot\textsf{Dcd}\!\Bigl(\frac{M}{\Delta}\Bigr).
$$

**步骤 7（客户端抽查验证——恶意 GS 的照妖镜）**。任意诚实 $U_j$ 可做 Fiat-Shamir 抽查：以 $\textsf{Hash}(\textsf{Com}_{\text{agg}}\|r)$ 为随机源抽取常数个 $U_{i_k}$，要求 GS 出示三元组 $(\theta_{i_k},\gamma_{i_k},\pi_{i_k})$，其中 $\pi_{i_k}$ 是"$\gamma_{i_k}$ 确为某 $r_{i_k}$ 对 $a$ 的合法 RLWE 像"的 $\Sigma$-协议证明（标准 RLWE 成员证明，3 轮可并发批处理）。$U_j$ 验证：
$$\textsf{Com}_{i_k}\stackrel{?}{=}\bigl(c_{i_k,1},\,c_{i_k,0}+\gamma_{i_k}\bigr)\ \wedge\ \sum_{i_k}\textsf{Com}_{i_k}\stackrel{?}{=}\textsf{Com}_{\text{agg}}.$$
若抽查失败，$U_j$ 广播欺诈证明（GS 出示的矛盾应答即可作为证据），本轮聚合被弃用。

#### 5.6.3 闭环公式链（从密钥到明文）

$$
\boxed{
\begin{aligned}
&\textbf{密钥：}\ b_i=-as_i+e_i\\
&\textbf{加密：}\ c_{i,0}+c_{i,1}s_i=m_i+E_i\\
&\textbf{聚合：}\ c_0+\textstyle\sum_i c_{i,1}s_i=\Delta\sum_i\textsf{Ecd}(w_i)+\sum_iE_i\\
&\textbf{部分解密：}\ \mu_i=c_{i,1}s_i+e_i^{\text{pd}}\\
&\textbf{分享：}\ f_i(0)=\mu_i,\ \tilde\mu_{i,j}=f_i(\alpha_j),\ F=\sum_if_i,\ F(0)=\sum_i\mu_i\\
&\textbf{重构：}\ \mu^{*}=\sum_{j\in T}\lambda_j^{(T)}F(\alpha_j)=\sum_i\mu_i\\
&\textbf{解密：}\ M=c_0+\mu^{*}\approx\Delta\textstyle\sum_i\textsf{Ecd}(w_i)\ \Rightarrow\ w_G=\textsf{Dcd}(M/\Delta)/|\mathcal{U}_{\text{live}}|
\end{aligned}}
$$

### 5.8 安全性分析

**定理 1（密文隐私，IND-CPA 归约）**。在决策 RLWE 假设下，GS 与 $\le t-1$ 个合谋 UAV 不能区分 $\theta_i$ 与随机 $R_q^2$ 元素。
*证明要点*：$\theta_i=(v_ib_i+m_i+e_{i,0},\;v_ia+e_{i,1})$。$(b_i,a)$ 与 $(v_ia+e_{i,1},a)$ 均为 RLWE 样本；两个 RLWE 假设下的替换把 $c_{i,0},c_{i,1}$  sequential hybrid 成均匀随机，中间间隙恰为 $m_i$，故密文泄露 $m_i$ 的概率可忽略。$\blacksquare$

**定理 2（部分解密隐私，信息论）**。GS 从 $\{\tilde\mu_j\}_{j\in T}$（任意 $|T|\le t-1$）与 $\{e_{i,j}\}$ 中获得的关于 $\{\mu_i\}$ 的信息为 0。
*证明要点*：① $e_{i,j}$ 在认证加密下语义安全，GS 无 $k_{ij}$，视图与随机串不可区分。② 对固定 $\{\mu_i\}$，份额多项式的随机系数空间 $(R_q^{\,t-1})^{n}$ 到任意 $t-1$ 个求值点的映射是满射且每纤维等势，故后验=先验。③ $\mu_i$ 本身被 $e_i^{\text{pd}}$ 淹没：即使 $F(0)$ 被部分推断，$F(0)=\sum_i(c_{i,1}s_i+e_i^{\text{pd}})$，个体项被独立大噪声覆盖，与 P9 同理。$\blacksquare$

**定理 3（阈值重构正确性）**。任意 $t$ 个诚实的 $\tilde\mu_j$ 使 $M/\Delta$ 解码误差以 $1-\textsf{negl}$ 落在 CKKS 精度内。
*证明要点*：式 (2) 是 Shamir 的精确性质（$R_q$ 上 $\alpha_j$ 可逆条件成立）；总噪声 $B=\sum_i(\|E_i\|+\|e_i^{\text{pd}}\|)$ 有界，按 CKKS 参数标准取 $\Delta\gg B\sqrt{N}$ 即可。$\blacksquare$

**定理 4（篡改检测 soundness）**。若 GS 在步骤 2 用 $\tilde\theta\ne\theta_{i^*}$ 替换诚实 $U_{i^*}$ 的密文，单次抽查以 $\ge \rho(1-\textsf{negl})$ 概率发现（$\rho$ 为抽样比例），$k$ 次独立抽查漏检率 $\le(1-\rho)^k+\textsf{negl}$。
*证明要点*：承诺分量加法同态且 $a$ 固定，故 $\textsf{Com}_{\text{agg}}$ 第二分量唯一确定 $c_0+\sum_i\gamma_i$；替换 $\theta_{i^*}$ 必改变 $c_0$，而 $\gamma_{i^*}$ 与 $\pi_{i^*}$ 绑定原 $r_{i^*}$，诚实验证者重算 $\textsf{Com}_{i^*}$ 即得不一致。GS 要同时伪造一致的 $\gamma'$ 与 $\Sigma$-证明 $\pi'$，等价于在未知 $r_{i^*}$ 下解 RLWE 像成员关系，概率可忽略。$\blacksquare$

**合谋/掉线边界**：$\ge t$ 方合谋可重构 $\sum_i\mu_i$，但只能得到他们本就应得的聚合结果（协议本身输出），不能拆解个体；掉线 $\le n-t$ 由定理 3 保证；GS 合谋 $<t$ 个 UAV 时定理 2、4 同时成立。

## 方案二　JZD-FL：联合 DKG 零和掩码加性 RLWE 联邦学习（标准 FL 架构）

> **定位**：研究点 R2。目标：**密钥生成彻底去 TTP**（优于 P5 的 AS、P6 的 KDC、P7 的 Key Manager），用 Pedersen 风格分布式密钥生成（DKG）+ 加性 RLWE/CKKS + 贡献感知客户端选择，同时把 straggler 规避和密文膨胀控制一起做掉。**本方案是"验证联邦学习"向"隐私保护联邦学习"的密码化升级**——服务器只输出聚合密文，客户端可验证聚合正确性（承诺链），任何单点都不掌握全局私钥。

### 5.1 场景

多个机构级 UAV 编队（不同搜救队、电力巡检中队、农业植保队）通过卫星/地面站链路参与 **cross-silo 联邦学习**。编队之间**互不分享解密密钥**，也不接受任何常驻 TTP/TEE；编队间算力与链路差异大（straggler 严重）、数据强 Non-IID、链路带宽珍贵。要求：

- 无 KDC/TA/TEE/AS 生成或托管密钥；
- 任一客户端（或服务器）单独无法解密其他客户端的更新；
- 通信量通过 CKKS 打包 + 稀疏化 + 残差编码控制；
- 高掉队率下仍可完成聚合（只需 $t$-out-of-$n$ 在线解密）。

### 5.2 要解决的问题（与最新研究的差距）

| 现有方案 | 已解决 | 未解决（本方案补齐） |
|---|---|---|
| P5 ESAFL（最新加性同态方案） | 无部分解密份额分发、效率逼近单密钥 | **初始化依赖可信 AS** 分发 $s=\sum_i s_i$；仅加法；未讨论掉线；无可验证性 |
| P6 FedPHE | 打包 + 稀疏 + 贡献感知选择 | **强依赖 KDC**；本质是共享密钥；Shamir 恢复需 $th$ 人在线 |
| P7 MASER | MKHE 效率 | 依赖可信 Key Manager；无掉线容忍 |
| P1 SecAgg | 抗掉线 | 无 HE，不能密文域加权；$O(n^2)$ 协商 |

**核心差距**：P5 的"聚合解密密钥 $s=\sum_i s_i$"思想很好，但它把"如何安全得到 $s$ 并分发给各方"留给了可信 AS。本方案用 **Pedersen 风格 DKG**（Feldman-VSS + 联合公钥聚合）让 $s$ 从不出现在任何单一实体中：每个客户端贡献 $s_i$，全局公钥 $pk=(b,a)$ 由全体 $b_i$ 相加而成；同时 $s$ 的 Shamir 份额分散在全体客户端，$t$-out-of-$n$ 才能解密——**去掉了 AS，且比 P6 更彻底（无需 KDC 混淆数，零和掩码在密文聚合后自动消去）**。

### 5.3 创新点 / 总体设计目标

1. **无 TTP 的阈值密钥生成（联合 DKG）**：$s=\sum_i s_i$ 由分布式生成，任何单点（含服务器）不知 $s$；每个客户端只持 $s$ 的 Shamir 份额。
2. **加性 RLWE + SecAgg 风格零和掩码**：客户端加密 $w_i+\sigma_i$（$\sum_i\sigma_i=0$），服务器密文相加后掩码自动消去——无需 P5 的初始化密钥分发信道，也无需 P6 的 KDC 混淆。
3. **贡献感知 + 掉队规避选择**：服务器在 DP 扰动 sketch 上聚类，优先选择高贡献低延迟客户端子集，未被选中者不上传全量密文（省带宽）。
4. **严格优于 P5/P6/P7**：无 AS/KDC/Key Manager（优于 P5/P6/P7）；支持 $t$-out-of-$n$ 掉线（优于 P5/P7）；支持密文域加权与打包（优于 P1）。

### 5.4 威胁模型

- **参数服务器 S**：半诚实（诚实但好奇），严格执行协议但试图推断隐私；可与 $<t$ 个客户端合谋。
- **UAV/编队客户端 $C_i$**：半诚实，最多 $t-1$ 个合谋（含与 S 合谋）无法重构全局秘密 $s$。
- **外部敌手**：RLWE 语义安全保证密文不可区分；信道经认证加密（TLS）。
- **掉线容忍**：解密阶段最多 $n-t$ 个客户端掉线；选择阶段天然过滤 straggler（只选最快/高贡献子集）。
- **可信实体**：**无在线 TTP/TEE/KDC/AS**；仅公开 CRS（或 PRG 种子生成 $a$）；可选 ZKPoK 验证每个 $pk_i$ 格式正确（防恶意客户端投毒公钥）。

| $R=\mathbb{Z}[X]/(X^N+1)$，$R_q=R/qR$ | 分圆环与密文空间 |

### 5.6 方案设计：实体交互与闭环公式推导

**实体**：客户端 $\{C_1,\dots,C_n\}$（UAV 编队）；中心参数服务器 $S$。

#### 5.6.1 Setup：联合 DKG（一次，或周期性刷新）

1. 每个 $C_i$ 本地采样 $s_i\leftarrow\chi_s$、$e_i\leftarrow\chi_e$，计算并广播：
$$b_i=-a\,s_i+e_i\pmod q,\qquad pk_i=(b_i,a).$$
2. **Feldman-VSS**：$C_i$ 把 $s_i$ 用 $(t,n)$-Shamir 拆为 $f_i(X)$，广播对 $f_{i,k}$ 的承诺 $\textsf{Com}_{i,k}=g^{f_{i,k}}$（或格基承诺），把份额 $f_i(\alpha_j)$ 经认证信道发给 $C_j$。$C_j$ 验证份额与承诺一致（离散对数/格承诺的开一致性）。
3. **联合公钥聚合**：$S$（或任何人）计算：
$$b=\sum_{i=1}^n b_i=-a\underbrace{\sum_i s_i}_{s}+\underbrace{\sum_i e_i}_{e}\pmod q,\qquad pk=(b,a).$$
4. **份额聚合**：每个 $C_j$ 聚合收到的全部分额：
$$\tilde s_j=\sum_{i=1}^n f_i(\alpha_j)=F(\alpha_j)\pmod q,\quad F(X)=\sum_i f_i(X),\ F(0)=s.$$
**$s$ 从不以整体形式存在于任何实体**；$S$ 只见 $pk$。

#### 5.6.2 第 $r$ 轮训练

**步骤 1（零和掩码协商）**。沿用 P1 SecAgg 的 DH 种子思想：$C_i$ 与 $C_j$ 协商 $s_{ij}$，本地计算：
$$\sigma_i=\sum_{j<i}s_{ij}-\sum_{j>i}s_{ij}\ \Rightarrow\ \sum_{i\in\mathcal{S}}\sigma_i=0\ (\text{对任意子集 }\mathcal{S}\text{ 成立，因为每对 }(i,j)\text{ 的贡献 }s_{ij}-s_{ij}=0).$$
掩码的作用：即使未来某轮 $<t$ 个客户端合谋拿到部分解密份额，也无法从密文中摘除他人掩码反推个体更新（见 5.8 定理 3）。

**步骤 2（贡献感知选择，每 $r_0$ 轮一次）**。每个 $C_i$ 计算本地更新的轻量 sketch（如符号比例向量 $\mathbf{y}_i$），加 Laplace 噪声 $\boldsymbol\xi_i$（$\varepsilon$-DP）后发给 $S$；$S$ 用 Gap Statistic + K-means 聚类，选择覆盖主要数据分布且历史延迟低的子集 $\mathcal{S}$，广播选择结果与聚类摘要。未被选中的 $C_i$ 本轮只上传 sketch 不上传密文。

**步骤 3（本地训练与 CKKS 打包加密）**。$C_i\in\mathcal{S}$ 训练得 $w_i$，应用稀疏化 $\tilde w_i=\textsf{TopK}_\rho(w_i)$（与 P7 共识剪枝思想兼容，可叠加），编码缩放并加掩码：
$$m_i=\Delta\cdot\textsf{Ecd}(\tilde w_i+\sigma_i)\in R_q.$$
采样 $v_i\leftarrow\chi_s$，$e_{i,0},e_{i,1}\leftarrow\chi_e$，用**联合公钥**加密：
$$
\begin{aligned}
c_{i,0}&=v_i\,b+m_i+e_{i,0}\pmod q,\\
c_{i,1}&=v_i\,a+e_{i,1}\pmod q.
\end{aligned}
$$
相位展开（代入 $b=-as+e$）：
$$
c_{i,0}+c_{i,1}s=v_i(b+as)+m_i+e_{i,0}+e_{i,1}s=m_i+\underbrace{v_ie+e_{i,0}+e_{i,1}s}_{E_i}\approx m_i\pmod q. \tag{3}
$$
$C_i\to S$：$(c_{i,0},c_{i,1})$（CKKS 打包使一个密文装 $N/2$ 个浮点参数，通信量远小于明文逐维上传）。

**步骤 4（服务器密文聚合）**。$S$ 对 $\mathcal{S}$ 中密文做分量加法：
$$C_0=\sum_{i\in\mathcal{S}}c_{i,0}\pmod q,\qquad C_1=\sum_{i\in\mathcal{S}}c_{i,1}\pmod q.$$
由式 (3) 与零和性质：
$$
\begin{aligned}
C_0+C_1s&=\sum_{i\in\mathcal{S}}m_i+\sum_i E_i=\Delta\sum_i\textsf{Ecd}(\tilde w_i+\sigma_i)+\sum_iE_i\\
&=\Delta\cdot\textsf{Ecd}\Bigl(\sum_i\tilde w_i\Bigr)+\Delta\cdot\textsf{Ecd}\Bigl(\underbrace{\sum_i\sigma_i}_{=0}\Bigr)+\sum_iE_i\\
&\approx\Delta\cdot\textsf{Ecd}\Bigl(\sum_{i\in\mathcal{S}}\tilde w_i\Bigr)\pmod q. \tag{4}
\end{aligned}
$$
**掩码在密文域自动消去**，$S$ 只见聚合密文 $(C_0,C_1)$，无 $s$ 无法解密。

**步骤 5（阈值部分解密与重构）**。每个在线 $C_j\in\mathcal{S}_{\text{dec}}$（$|\mathcal{S}_{\text{dec}}|\ge t$）用其全局份额 $\tilde s_j$ 计算部分解密并加淹没噪声：
$$pd_j=C_1\cdot\tilde s_j+\eta_j\pmod q,\quad \eta_j\leftarrow\chi_e^{\text{pd}}.$$
$C_j\to S$：$pd_j$。$S$ 收集任意 $t$ 个份额，Lagrange 重构：
$$\mu=\sum_{j\in T}\lambda_j^{(T)}pd_j\approx C_1\cdot F(0)=C_1\cdot s\pmod q,\qquad |T|\ge t. \tag{5}$$

**步骤 6（全局解密与模型更新）**。$S$ 计算：
$$M=C_0+\mu\overset{(4)(5)}{\approx}\Delta\cdot\textsf{Ecd}\Bigl(\sum_{i\in\mathcal{S}}\tilde w_i\Bigr)\pmod q,$$
$$w_G=\frac{1}{|\mathcal{S}|}\cdot\textsf{Dcd}\!\Bigl(\frac{M}{\Delta}\Bigr).$$
$S$ 将 $w_G$ 广播；客户端可用与方案一相同的承诺抽查验证 $S$ 未替换密文（承诺 $\textsf{Com}_i=(c_{i,1},c_{i,0}+ar_i)$ 加法同态，见方案一 5.6 步骤 3）。

#### 5.6.3 闭环公式链

$$
\boxed{
\begin{aligned}
&\textbf{DKG：}\ b=\sum_ib_i=-a\sum_is_i+\sum_ie_i=-as+e,\quad s\text{ 不整体存在}\\
&\textbf{份额：}\ \tilde s_j=F(\alpha_j)=\sum_if_i(\alpha_j),\quad F(0)=s\\
&\textbf{掩码：}\ \sigma_i=\sum_{j<i}s_{ij}-\sum_{j>i}s_{ij},\quad \sum_{i\in\mathcal{S}}\sigma_i=0\\
&\textbf{加密：}\ c_{i,0}+c_{i,1}s=\Delta\,\textsf{Ecd}(\tilde w_i+\sigma_i)+E_i\\
&\textbf{聚合：}\ C_0+C_1s=\Delta\,\textsf{Ecd}(\sum_i\tilde w_i)+\sum_iE_i\quad(\text{掩码消去})\\
&\textbf{部分解密：}\ pd_j=C_1\tilde s_j+\eta_j\\
&\textbf{重构：}\ \mu=\sum_{j\in T}\lambda_j^{(T)}pd_j=C_1s\\
&\textbf{解密：}\ M=C_0+\mu\approx\Delta\,\textsf{Ecd}(\sum_i\tilde w_i)\ \Rightarrow\ w_G=\textsf{Dcd}(M/\Delta)/|\mathcal{S}|
\end{aligned}}
$$

### 5.8 安全性分析

**定理 1（联合公钥隐私）**。在 RLWE 与 Shamir $(t,n)$ 阈值安全性下，$S$ 与任意 $\le t-1$ 个客户端合谋不能重构 $s$ 或区分任何 $(c_{i,0},c_{i,1})$ 对应的明文。
*证明要点*：① $b=\sum_i b_i$ 中每个 $b_i$ 是 RLWE 样本，$\sum_i b_i$ 仍是 RLWE 样本（分布可加性），故 $pk$ 不泄露 $s$。② $s$ 的 Shamir 份额 $\tilde s_j$ 满足：任意 $\le t-1$ 份对 $s$ 的信息为 0（完美阈值安全性）。③ 密文 $(c_{i,0},c_{i,1})$ 在 $pk$ 下的 IND-CPA 安全性由 RLWE 归约保证（同方案一定理 1）。$\blacksquare$

**定理 2（正确性——零和掩码消去）**。对任意 $\mathcal{S}$，式 (4) 精确成立：$\sum_{i\in\mathcal{S}}\sigma_i=0$。
*证明要点*：$\sum_i\sigma_i=\sum_i(\sum_{j<i}s_{ij}-\sum_{j>i}s_{ij})=\sum_{i<j}(s_{ij}-s_{ij})=0$，恒等式与 $\mathcal{S}$ 无关（成对种子在全集上两两消去）。$\blacksquare$

**定理 3（抗"份额级"合谋反推）**。即使某轮 $\le t-1$ 个客户端合谋并共享各自的 $\tilde s_j$ 与 $pd_j$，他们仍无法从 $(C_0,C_1)$ 中解出任何诚实客户端的 $\tilde w_i$。
*证明要点*：合谋者掌握 $C_1s$ 的部分信息（$\le t-1$ 份 $pd_j$），但 $C_1s$ 本身满足 $C_0+C_1s\approx\Delta\textsf{Ecd}(\sum_i\tilde w_i)$——这是协议**本应输出**的聚合结果，不构成额外泄露。对个体 $\tilde w_i$ 的推断需要摘除他人贡献，等价于在未知他人掩码 $\sigma_j$（DH 种子 $s_{ij}$ 未被合谋方持有）与未知 RLWE 明文的情况下求解，由 RLWE 假设与 DH 假设联合保证不可行。$\blacksquare$

**定理 4（掉线容忍）**。解密只需任意 $t$ 个 $pd_j$；选择阶段未被选中的客户端不参与解密，天然规避 straggler。
*证明要点*：Shamir $(t,n)$ 的重构性质 + 步骤 2 的选择机制。$\blacksquare$

**与 P5/P6/P7 的严格对比**：P5 需可信 AS 初始化 $s$（本方案用 DKG 替代）；P6 需 KDC 且恢复需 $th$ 人在线（本方案无 KDC，$t$-out-of-$n$ 即可）；P7 需可信 Key Manager 且无掉线容忍（本方案无 Key Manager，支持 $n-t$ 掉线）。代价：Setup 需一轮 VSS 交互（一次性，可周期性 proactive 刷新抗长期合谋）。

## 方案三　UEC-BR：UAV-Edge-Cloud 层次 CKKS + 边缘拜占庭过滤 + 云阈值解密（层次型 FL 架构）

> **定位**：研究点 R3。**UAV-Assist / Edge-Assist 场景**的典型问题：边缘节点（楼顶基站、车载边缘、UAV 簇头）由第三方运营，**半可信**——按协议转发聚合但想偷窥辖区 UAV 隐私，甚至物理被俘获；辖区内部分 UAV 被攻陷上传拜占庭更新。本方案让边缘**只做 CKKS 密文聚合 + DP-sketch 拜占庭过滤**（永不掌握明文与云私钥），云密钥以 $(t,l)$-Shamir 分散在 $l$ 个边缘，任意 $t$ 个边缘联合才能助云解密。**本方案属于"鲁棒聚合联邦学习"——同时解决隐私与拜占庭**。

### 5.1 场景

城市级 UAV 巡检/搜救系统：大量小型 UAV 接入本地边缘服务器 $A_1,\dots,A_l$（基站/车载节点/UAV 簇头），边缘再连远程云 $C$。边缘由不同运营商部署，**诚实但好奇**且物理暴露；云管理员好奇；部分 UAV 被攻陷上传恶意更新；UAV 与边缘均会掉线。要求：

- 边缘看不到辖区内任何 UAV 的明文更新，也看不到其它边缘辖区的聚合模型；
- 边缘层能过滤本地拜占庭 UAV；
- 云只需轻量验证（范数 + 哈希链）即接受全局模型；
- 支持边缘与 UAV 掉线（云解密需 $t$-out-of-$l$ 边缘在线）。

### 5.2 要解决的问题（与最新研究的差距）

| 现有方案 | 已解决 | 未解决（本方案补齐） |
|---|---|---|
| P11 PPBR（本目录最新 HFL 方案） | 端-边-云隐私 + 拜占庭鲁棒 | PLHE **单密钥托管在单一边服务器**——边被俘获即全边层解密；BFV 整数需量化；无云侧阈值解密 |
| P8 SKHE | 云-边-端单密钥 CKKS | 依赖 TA + 云端 TEE；边缘仅转发，无边缘层聚合与过滤 |
| P6 FedPHE | 贡献感知选择 | 标准 cross-silo，无边缘层，不防拜占庭 |
| P1 SecAgg | 抗掉线 | 边缘层做 $O(n_i^2)$ pairwise 协商会迅速耗尽 UAV 电量 |

**核心差距**：P11 把隐私与鲁棒做进了 HFL，但信任模型仍是"单一边服务器持密钥"。本方案把云私钥 $s_A$ 用 $(t,l)$-Shamir 拆给 $l$ 个边缘：**单个/少数边缘（$\le t-1$）与云合谋也无法解密**，从结构上消除 P11 的单点密钥托管；同时用 CKKS 替代 BFV，免去整数量化损失。

### 5.3 创新点 / 总体设计目标

1. **边缘层 CKKS 密文聚合**：UAV 用云公钥加密更新，边缘只做分量加法，永远不见明文。
2. **边缘侧拜占庭过滤**：UAV 上传 DP 扰动符号统计 sketch（CLDP），边缘用 trimmed k-means 剔除异常簇后再聚合密文——过滤依据是差分隐私统计量，过滤动作本身不泄露隐私。
3. **云密钥 $(t,l)$ 边缘分片 + 云阈值解密**：任意 $t$ 个边缘提供部分解密份额云才能解密；$\le t-1$ 个边缘被俘获不影响机密性。
4. **轻量云验证**：解密后检查全局更新范数与 UAV 哈希链，拒绝异常聚合。
5. **严格优于 P11**：密钥托管从"单边"变为"阈值分散"；BFV→CKKS 免量化；边缘掉线容忍 $l-t$。

### 5.4 威胁模型

- **UAV 客户端**：半诚实；每个边缘辖区内拜占庭比例 $\beta<0.5$（可上传任意错误更新，但不能伪造他人签名）。
- **边缘服务器 $A_i$**：半诚实（好奇、可与云合谋），物理可被俘获；**任意 $\le t-1$ 个边缘与云合谋无法重构 $s_A$**。
- **云 $C$**：半诚实，不破坏协议执行，但试图从密文/统计量推断隐私。
- **KGA（密钥生成机构）**：仅初始化时存在，生成云密钥并分发份额后**离线删除私钥**；不与运行期实体合谋。（可用方案二的联合 DKG 替换，进一步去信任。）
- **掉线容忍**：边缘辖区内可信 UAV 数 $\ge 2$ 即可做有意义过滤；云解密需 $t$-out-of-$l$ 边缘在线。
- **外部敌手**：RLWE 语义安全；信道认证加密；UAV 身份经预置证书绑定抗 Sybil。

### 5.5 符号系统

| 符号 | 含义 |
|---|---|
| $A_i$（$i=1..l$） | 边缘服务器；$U_{i,j}$ 为 $A_i$ 辖区内第 $j$ 架 UAV |
| $s_A,e_A,b_A$ | 云私钥、误差、云公钥分量 $b_A=-as_A+e_A$；$pk_A=(b_A,a)$ |
| $s_{A,i}=f_A(\alpha_i)$ | $s_A$ 的 $(t,l)$-Shamir 份额（$KGA$ 分发，$\deg f_A=t-1$） |
| $c_{i,j}=(c_{i,j,0},c_{i,j,1})$ | $U_{i,j}$ 用 $pk_A$ 加密的 CKKS 密文 |
| $\mathbf{y}_{i,j}=\mathbf{s}_{i,j}+\boldsymbol\xi_{i,j}$ | CLDP 扰动符号 sketch（$\boldsymbol\xi$ 为 Laplace 噪声） |
| $h_{i,j}=H(c_{i,j,0},c_{i,j,1})$ | UAV 密文哈希 |
| $C_i=(C_{i,0},C_{i,1})$ | 边缘 $A_i$ 的辖区聚合密文 |

### 5.6 方案设计：实体交互与闭环公式推导

**实体**：UAV $U_{i,j}$；边缘 $A_1..A_l$；云 $C$；离线 KGA。

#### 5.6.1 Setup（KGA 一次性，之后离线）

KGA 采样 $s_A\leftarrow\chi_s$、$e_A\leftarrow\chi_e$，生成云公钥：
$$b_A=-a\,s_A+e_A\pmod q,\qquad pk_A=(b_A,a).$$
选 $(t,l)$-Shamir 多项式 $f_A(X)$（$f_A(0)=s_A$），经安全信道把 $s_{A,i}=f_A(\alpha_i)$ 发给 $A_i$；**删除 $s_A$ 并离线**。$pk_A$ 公开全员。

#### 5.6.2 第 $r$ 轮训练

**步骤 1（云广播）**。$C$ 广播全局模型 $w^{(r)}$、$pk_A$、公开参数。

**步骤 2（UAV 本地训练 + 加密）**。$U_{i,j}$ 本地训练得 $\Delta w_{i,j}$，编码缩放：
$$m_{i,j}=\Delta\cdot\textsf{Ecd}(\Delta w_{i,j})\in R_q.$$
采样 $v_{i,j}\leftarrow\chi_s$，$e_{i,j,0},e_{i,j,1}\leftarrow\chi_e$：
$$
\begin{aligned}
c_{i,j,0}&=v_{i,j}\,b_A+m_{i,j}+e_{i,j,0}\pmod q,\\
c_{i,j,1}&=v_{i,j}\,a+e_{i,j,1}\pmod q.
\end{aligned}
$$
相位：$c_{i,j,0}+c_{i,j,1}s_A=m_{i,j}+E_{i,j}\approx\Delta\,\textsf{Ecd}(\Delta w_{i,j})\pmod q.$ 同时计算 CLDP sketch $\mathbf{y}_{i,j}$ 与哈希 $h_{i,j}$。
$U_{i,j}\to A_i$：$(c_{i,j},\mathbf{y}_{i,j},h_{i,j})$。

**步骤 3（边缘拜占庭过滤）**。$A_i$ 对 $\{\mathbf{y}_{i,j}\}$ 做 trimmed k-means 聚类，剔除离群簇得可信集合 $U_i^{(T)}$（要求 $|U_i^{(T)}|/|U_i|\ge 1-\beta$，$\beta<0.5$）；验证 $h_{i,j}$ 与密文一致。

**步骤 4（边缘 CKKS 密文聚合）**。$A_i$ 只做分量加法：
$$C_{i,0}=\sum_{j\in U_i^{(T)}}c_{i,j,0}\pmod q,\qquad C_{i,1}=\sum_{j\in U_i^{(T)}}c_{i,j,1}\pmod q,$$
相位：$C_{i,0}+C_{i,1}s_A=\sum_j m_{i,j}+\sum_jE_{i,j}\approx\Delta\,\textsf{Ecd}(\sum_j\Delta w_{i,j})\pmod q.$ 注意 $A_i$ **无 $s_A$**，无法解密。
$A_i\to C$：$(C_{i,0},C_{i,1})$、$|U_i^{(T)}|$、聚合哈希 $H_i=\sum_{j\in U_i^{(T)}}h_{i,j}$。

**步骤 5（云全局聚合）**：
$$C_0=\sum_{i=1}^l C_{i,0}\pmod q,\qquad C_1=\sum_{i=1}^l C_{i,1}\pmod q,$$
$$C_0+C_1s_A=\Delta\,\textsf{Ecd}\Bigl(\sum_{i=1}^l\sum_{j\in U_i^{(T)}}\Delta w_{i,j}\Bigr)+\text{噪声}\pmod q. \tag{6}$$

**步骤 6（云阈值解密）**。$C$ 向任意在线边缘子集 $T\subseteq[l]$（$|T|\ge t$）请求份额。每个 $A_i$ 计算：
$$pd_i=C_1\cdot s_{A,i}+\eta_i\pmod q,\quad \eta_i\leftarrow\chi_e^{\text{pd}},\qquad A_i\to C.$$
$C$ 重构：
$$\mu=\sum_{i\in T}\lambda_i^{(T)}pd_i\approx C_1\cdot f_A(0)=C_1s_A\pmod q. \tag{7}$$

**步骤 7（全局解密 + 轻量验证）**：
$$M=C_0+\mu\overset{(6)(7)}{\approx}\Delta\,\textsf{Ecd}\Bigl(\sum_{i,j}\Delta w_{i,j}\Bigr),\qquad
w_G^{(r+1)}=w^{(r)}-\eta\cdot\frac{1}{N}\textsf{Dcd}\!\Bigl(\frac{M}{\Delta}\Bigr),\ N=\sum_i|U_i^{(T)}|.$$
验证：① 范数检查 $\|\textsf{Dcd}(M/\Delta)\|_2\le\Theta$；② 哈希链比对 $H(C_{i,0},C_{i,1})$ 与 $A_i$ 上报的 $H_i$ 派生值；③ 可选承诺抽查（同方案一）。任一失败弃用本轮。

#### 5.6.3 闭环公式链

$$
\boxed{
\begin{aligned}
&\textbf{密钥：}\ b_A=-as_A+e_A;\quad s_A=\sum_{i\in T}\lambda_i^{(T)}s_{A,i}\\
&\textbf{加密：}\ c_{i,j,0}+c_{i,j,1}s_A=\Delta\,\textsf{Ecd}(\Delta w_{i,j})+E_{i,j}\\
&\textbf{边缘聚合：}\ C_{i,0}+C_{i,1}s_A=\Delta\,\textsf{Ecd}(\textstyle\sum_{j\in U_i^{(T)}}\Delta w_{i,j})+\sum_jE_{i,j}\\
&\textbf{云聚合：}\ C_0+C_1s_A=\Delta\,\textsf{Ecd}(\textstyle\sum_{i,j}\Delta w_{i,j})+\sum_{i,j}E_{i,j}\\
&\textbf{部分解密：}\ pd_i=C_1s_{A,i}+\eta_i;\quad \mu=\sum_{i\in T}\lambda_i^{(T)}pd_i=C_1s_A\\
&\textbf{解密：}\ M=C_0+\mu\ \Rightarrow\ w_G^{(r+1)}=w^{(r)}-\frac{\eta}{N}\textsf{Dcd}(M/\Delta)
\end{aligned}}
$$

### 5.8 安全性分析

**定理 1（边缘不可解密）**。任意 $\le t-1$ 个边缘（含与云合谋）不能重构 $s_A$。
*证明要点*：Shamir $(t,l)$ 完美阈值安全性——$\le t-1$ 份份额对 $s_A$ 后验分布无影响；$KGA$ 已删除 $s_A$ 且不与运行期合谋，故运行期无任何实体持有 $s_A$ 整体。$\blacksquare$

**定理 2（密文隐私）**。云与全部边缘（$\le t-1$ 合谋）不能从 $(C_0,C_1)$ 或任何 $c_{i,j}$ 推断个体 $\Delta w_{i,j}$。
*证明要点*：$(c_{i,j,0},c_{i,j,1})$ 在 $pk_A$ 下的 IND-CPA 由 RLWE 归约（同方案一定理 1）；边缘只见分量之和 $C_{i,0}+C_{i,1}s_A$ 的加密形态，无 $s_A$ 则与随机不可区分；云只见 $(C_0,C_1)$ 与 $pd_i$，由定理 1 云不知 $s_A$，且 $pd_i$ 被 $\eta_i$ 淹没。$\blacksquare$

**定理 3（拜占庭过滤有效性）**。在 $\beta<0.5$ 且 Non-IID 强度有界（sketch 分布可分离）条件下，trimmed k-means 以 $1-\textsf{negl}(n_i)$ 概率剔除全部拜占庭 UAV。
*证明要点*：CLDP 噪声幅度 $\|\boldsymbol\xi\|_\infty=O(\log d/\varepsilon)$ 有界，诚实 sketch 落在以簇中心为心的紧集内；拜占庭更新经 $\Theta$ 裁剪后范数有界，若其 sketch 偏离所有诚实簇中心 $>2\|\boldsymbol\xi\|$ 即被判离群。$\beta<0.5$ 保证 trimmed 均值不被拖偏（标准鲁棒统计论证）。$\blacksquare$

**定理 4（掉线容忍）**。云解密需 $t$-out-of-$l$ 边缘在线；单个边缘掉线只影响其辖区（该辖区本轮贡献缺失，全局聚合仍由其余边缘完成）。
*证明要点*：Shamir 重构性质 + 步骤 5 聚合对参与集合的任意子集封闭。$\blacksquare$

**与 P11 的严格对比**：P11 的单一边服务器持 PLHE 密钥 → 本方案 $(t,l)$ 阈值分散（定理 1）；P11 BFV 整数量化 → 本方案 CKKS 原生浮点；P11 边缘掉线即中断 → 本方案容忍 $l-t$ 边缘掉线（定理 4）。代价：初始化需 KGA（可换 DKG）；边缘需额外存储 $s_{A,i}$（一个 $R_q$ 元素）。

## 方案四　UCL-HFL：自组织 UAV 簇 + 分层 DKG + 簇间阈值解密 + Proactive Resharing（层次型 FL 架构）

> **定位**：研究点 R4。UAV 场景最独有的问题——**拓扑高速动态**：簇成员、簇头、与地面站的连接每轮都变，而现有方案（P1 的 pairwise 掩码、P9 的固定 $n$ P2P 份额、P8 的固定云-边-端）全部假设参与者集合相对固定。本方案的核心思想：**全局密钥永远不变，变的是"谁持有它的份额"**——簇成员变化只需簇内重新分配子份额；簇头更换通过 proactive resharing 把旧簇头份额迁移到新簇头，**全局公钥 $pk$ 与全局秘密 $s$ 均不重建**。

### 5.1 场景

广阔灾区/边境多架 UAV 自组织搜救：UAV 按位置、电量、信号强度动态结成 $l$ 个簇，每簇选举簇头 $CH_c$（电量/连接度最高者）作为边缘聚合节点；簇头与远程云/指挥中心交互。簇成员与簇头**每轮都可能变化**（飞出覆盖区、电量耗尽、被俘获）。要求：

- 簇结构动态变化时**不重新初始化全局密钥**（UAV 不重新生成密钥对、不重跑 DKG）；
- 任何单个簇头不能解密全局聚合结果；任意 $t$ 个簇头在线即可解密；
- 簇内 UAV 任意掉线不影响全局解密；
- 不依赖 TTP/TEE；簇头可被俘获但 $\le t-1$ 个。

### 5.2 要解决的问题（与最新研究的差距）

| 现有方案 | 已解决 | 未解决（本方案补齐） |
|---|---|---|
| P1 SecAgg | 抗掉线安全聚合 | pairwise 掩码绑定固定参与者，簇变化需重协商全部 $O(n^2)$ 种子 |
| P9 CDKS-LSS | 无 TTP 阈值解密 | P2P 份额交换量随 $n$ 增长，且份额绑定固定求值点 $\alpha_j$（固定身份） |
| P8 SKHE | 云-边-端单密钥 CKKS | 固定拓扑；边缘是固定 EN；TA+TEE 信任锚 |
| P4 SecFed | TEE 补掉线 | 簇头被俘获 + TEE 攻破 = 全局密钥丢失 |
| P7 MASER | MKHE 效率 | 所有客户端必须在线 partial decryption |

**核心差距**：把全局 RLWE 密钥 $s=\sum_c s_c$ 通过**两层秘密分享**分散到簇头：每个簇头 $CH_c$ 只持 $s$ 的一个 Shamir 份额 $\tilde s_c$，而 $\tilde s_c$ 又由簇内 UAV 的子份额聚合而成。簇成员进出 → 簇内子份额再分配（不动 $\tilde s_c$）；簇头更换 → proactive resharing 迁移 $\tilde s_c$（不动 $s$ 与 $pk$）。**密钥管理与拓扑变化解耦**——这是所有现有方案没有的能力。

### 5.3 创新点 / 总体设计目标

1. **簇头级 DKG（无 TTP）**：每个簇头贡献簇级分量 $s_c$，全局公钥 $pk$ 由簇公钥相加，全局秘密 $s=\sum_c s_c$ 不单独存在。
2. **簇内密文聚合**：UAV 用全局公钥加密，簇头只做 CKKS 加法，不见明文。
3. **簇间阈值解密**：任意 $t$-out-of-$l$ 簇头提供部分解密份额，云重构全局模型；单个/少数簇头掉线或被俘不影响。
4. **Proactive resharing（拓扑维护核心）**：簇分裂/合并/簇头更换时，旧簇头重采样同常数项的多项式把份额迁给新簇头集合，全局 $s$ 与 $pk$ 不变。
5. **严格优于 P1/P9/P8/P7**：拓扑动态性（唯一支持）、份额通信两层化（比 P9 的扁平 $O(n^2)$ 省）、无 TA/TEE（优于 P8）、簇头掉线容忍（优于 P7）。

### 5.4 威胁模型

- **UAV 客户端**：半诚实；簇内合谋 $<t_c$（$t_c$ 为簇内阈值）无法重构簇分量 $s_c$。
- **簇头 $CH_c$**：半诚实，可与云合谋；**云与 $\le t-1$ 个簇头合谋无法重构 $s$**。
- **云**：半诚实，只聚合簇密文与部分解密份额。
- **外部敌手**：监听、Sybil、GPS 欺骗；依赖预置证书/PKI 抗 Sybil；resharing 消息走认证加密信道。
- **掉线容忍**：簇内聚合无需秘密（任意子集 UAV 上传即可）；全局解密需 $t$-out-of-$l$ 簇头；簇头更换窗口内（resharing 完成前）旧簇头份额仍有效，新簇头份额逐步生效。
- **可信实体**：无在线 TTP/TEE/KDC；CRS/PRG 种子公开；簇头身份经选举 + 证书认证。

| 符号 | 含义 |
|---|---|
| $C_c$（$c=1..l$） | 第 $c$ 个 UAV 簇；$CH_c$ 为其簇头 |
| $s_c,e_c,b_c$ | 簇头 $CH_c$ 的簇级秘密分量、误差、簇公钥分量 $b_c=-as_c+e_c$ |
| $pk=(b,a)$，$b=\sum_cb_c$ | 全局公钥；$s=\sum_cs_c$ 全局秘密不单独存在 |
| $f_c(X)$，$\deg=t-1$，$f_c(0)=s_c$ | $CH_c$ 对簇间 Shamir 的分享多项式 |
| $\tilde s_{c'}=\sum_cf_c(c')$ | $CH_{c'}$ 持有的**全局**秘密份额（$F=\sum_cf_c$，$F(0)=s$） |

| $t_c,n_c$ | 簇内阈值与簇大小 |
| $c_{i,0},c_{i,1}$ | UAV $i$ 用全局 $pk$ 加密的密文 |

### 5.6 方案设计：实体交互与闭环公式推导

**实体**：UAV $i\in C_c$；簇头 $CH_c$；云。

#### 5.6.1 初始化：簇头级 DKG + 簇间阈值化

1. 每个 $CH_c$ 采样 $s_c\leftarrow\chi_s$、$e_c\leftarrow\chi_e$，发布簇公钥 $b_c=-as_c+e_c\pmod q$。
2. 全局公钥聚合（云或全员计算）：
$$b=\sum_{c=1}^l b_c=-a\underbrace{\sum_cs_c}_{s}+\underbrace{\sum_ce_c}_{e}\pmod q,\qquad pk=(b,a)\ \text{公开}.$$
3. **簇间 $(t,l)$-Shamir**：$CH_c$ 采样 $f_c(X)$（$f_c(0)=s_c$），把 $f_c(c')$ 经认证加密发给其它簇头 $CH_{c'}$；$CH_{c'}$ 聚合：
$$\tilde s_{c'}=\sum_{c=1}^l f_c(c')=F(c')\pmod q,\quad F(X)=\sum_cf_c(X),\ F(0)=s.$$
4. **簇内子份额绑定**（簇头更换的预备）：$CH_c$ 把 $s_c$ 在簇内用 $(t_c,n_c)$-Shamir 分享给 UAV 成员——平时不用，仅在 $CH_c$ 更换时由任意 $t_c$ 个 UAV 重构 $s_c$。

#### 5.6.2 第 $r$ 轮训练

**步骤 1（簇内 UAV 加密）**。$U_i\in C_c$ 训练得 $w_i$，编码 $m_i=\Delta\cdot\textsf{Ecd}(w_i)$，采样 $v_i,e_{i,0},e_{i,1}$，用全局 $pk$ 加密：
$$
c_{i,0}=v_i\,b+m_i+e_{i,0}\pmod q,\qquad c_{i,1}=v_i\,a+e_{i,1}\pmod q,
$$
$$c_{i,0}+c_{i,1}s=m_i+\underbrace{v_ie+e_{i,0}+e_{i,1}s}_{E_i}\approx\Delta\,\textsf{Ecd}(w_i)\pmod q.$$
$U_i\to CH_c$：$(c_{i,0},c_{i,1})$。

**步骤 2（簇内密文聚合）**。$CH_c$ 只做加法：
$$C_{c,0}=\sum_{i\in C_c}c_{i,0}\pmod q,\qquad C_{c,1}=\sum_{i\in C_c}c_{i,1}\pmod q,$$
$$C_{c,0}+C_{c,1}s\approx\Delta\,\textsf{Ecd}\Bigl(\sum_{i\in C_c}w_i\Bigr)\pmod q.$$
$CH_c\to$ 云：$(C_{c,0},C_{c,1})$、$|C_c|$。

**步骤 3（云全局聚合）**：
$$C_0=\sum_{c=1}^l C_{c,0}\pmod q,\qquad C_1=\sum_{c=1}^l C_{c,1}\pmod q,$$
$$C_0+C_1s\approx\Delta\,\textsf{Ecd}\Bigl(\sum_c\sum_{i\in C_c}w_i\Bigr)\pmod q. \tag{8}$$

**步骤 4（簇间阈值解密）**。云向任意 $t$ 个在线簇头 $T$ 请求份额；$CH_{c'}$ 用全局份额 $\tilde s_{c'}$ 计算：
$$pd_{c'}=C_1\cdot\tilde s_{c'}+\eta_{c'}\pmod q,\quad \eta_{c'}\leftarrow\chi_e^{\text{pd}}.$$
云重构：
$$\mu=\sum_{c'\in T}\lambda_{c'}^{(T)}pd_{c'}\approx C_1\cdot F(0)=C_1s\pmod q. \tag{9}$$

**步骤 5（全局解密与下发）**：
$$M=C_0+\mu\overset{(8)(9)}{\approx}\Delta\,\textsf{Ecd}\Bigl(\sum_{c,i}w_i\Bigr),\qquad
w_G=\frac{1}{N}\textsf{Dcd}\!\Bigl(\frac{M}{\Delta}\Bigr),\ N=\sum_c|C_c|.$$
云下发 $w_G$ 给各簇头，簇头转发簇内 UAV。

#### 5.6.3 动态拓扑维护：簇头更换与 Proactive Resharing

簇 $c$ 的簇头需更换（$CH_c\to CH_c^{\text{new}}$，因移动/掉线/被俘获嫌疑）时：

1. **旧簇头迁移**（若 $CH_c$ 仍在线且可信）：重采样 $g_c(X)$ 满足 $g_c(0)=s_c$（**常数项不变**），把 $g_c(c')$ 安全发给所有（新）簇头 $c'$。
2. **新簇头接入**：新簇头 $CH_{c'}^{\text{new}}$ 用 $g_c(c')$ 替换旧份额 $f_c(c')$，重算自己的全局份额 $\tilde s_{c'}^{\text{new}}=\sum_{c}g_c(c')$。
3. **旧簇头被俘获/掉线**：簇内任意 $t_c$ 个 UAV 用簇内子份额重构 $s_c$，代行步骤 1 的迁移角色（这正是步骤 1.4 簇内绑定的用途）。
4. **不变量**：全局 $F(0)=\sum_cs_c=s$ 不变 ⟹ 全局 $pk$ 不变 ⟹ **全体 UAV 的加密密钥无需更新**；只有簇头层的份额发生迁移。

#### 5.6.4 闭环公式链

$$
\boxed{
\begin{aligned}
&\textbf{簇头DKG：}\ b=\sum_cb_c=-a\sum_cs_c+\sum_ce_c=-as+e\\
&\textbf{簇间份额：}\ \tilde s_{c'}=F(c')=\sum_cf_c(c'),\ F(0)=s\\
&\textbf{加密：}\ c_{i,0}+c_{i,1}s=\Delta\,\textsf{Ecd}(w_i)+E_i\\
&\textbf{簇聚合：}\ C_{c,0}+C_{c,1}s=\Delta\,\textsf{Ecd}(\textstyle\sum_{i\in C_c}w_i)+\sum_iE_i\\
&\textbf{云聚合：}\ C_0+C_1s=\Delta\,\textsf{Ecd}(\textstyle\sum_{c,i}w_i)+\sum_{c,i}E_i\\
&\textbf{部分解密：}\ pd_{c'}=C_1\tilde s_{c'}+\eta_{c'};\ \mu=\sum_{c'\in T}\lambda_{c'}^{(T)}pd_{c'}=C_1s\\
&\textbf{解密：}\ M=C_0+\mu\ \Rightarrow\ w_G=\textsf{Dcd}(M/\Delta)/N\\
&\textbf{Resharing：}\ g_c(0)=s_c=f_c(0)\ \Rightarrow\ F^{\text{new}}(0)=s,\ pk\text{ 不变}
\end{aligned}}
$$

### 5.8 安全性分析

**定理 1（单簇头不可解密）**。任意 $\le t-1$ 个簇头（含与云合谋）不能重构 $s$。
*证明要点*：$\tilde s_{c'}$ 是 $s$ 的 Shamir $(t,l)$ 份额（$F(0)=s$ 精确成立），$\le t-1$ 份对 $s$ 信息为 0；$s=\sum_cs_c$ 且各 $s_c$ 由簇头本地生成不离开簇（除簇间分享多项式求值），无单点掌握 $s$。$\blacksquare$

**定理 2（密文隐私）**。云与 $\le t-1$ 簇头合谋不能从任何 $c_i$ 或 $(C_0,C_1)$ 推断个体 $w_i$。
*证明要点*：密文在全局 $pk$ 下的 IND-CPA 由 RLWE 归约；$b=\sum_cb_c$ 仍是 RLWE 样本（可加性），故 $pk$ 不泄露 $s$；云只见簇聚合密文与 $pd_{c'}$，由定理 1 无 $s$，$pd_{c'}$ 被 $\eta_{c'}$ 淹没。$\blacksquare$

**定理 3（resharing 正确性与前向安全）**。簇头更换后：① 新份额集合 $\{\tilde s_{c'}^{\text{new}}\}$ 仍是 $s$ 的有效 $(t,l)$ Shamir 份额；② 被更换的旧簇头不再持有有效份额（若其被俘获，仅泄露旧多项式 $f_c$ 的求值，而新多项式 $g_c$ 独立随机，旧视图对新份额无信息）。
*证明要点*：① $F^{\text{new}}(X)=\sum_{c'\ne c}f_{c'}(X)+g_c(X)$，$F^{\text{new}}(0)=\sum_{c'\ne c}s_{c'}+s_c=s$，且 $\deg\le t-1$，故插值性质保持。② $g_c$ 与 $f_c$ 独立采样，旧簇头知的 $f_c(c')$ 对 $g_c(c')$ 条件独立；满足 proactive security 定义（Ostrosky-Yung 风格，对抗移动敌手）。$\blacksquare$

**定理 4（掉线与拓扑变化容忍）**。簇内 UAV 任意掉线不影响其它簇；全局解密需 $t$-out-of-$l$ 簇头；簇头更换期间（resharing 进行中）旧份额仍有效，新份额生效后旧份额作废，全程解密能力不中断（只要 $\ge t$ 个簇头始终在线）。
*证明要点*：聚合步骤对参与子集封闭 + Shamir 重构性质 + 定理 3 的份额迁移连续性。$\blacksquare$

**与现有方案的严格对比**：对 P1，簇变化无需重协商 $O(n^2)$ pairwise 种子（只有簇头层 $O(l^2)$ 且仅在更换时）；对 P9，份额通信从扁平 $O(n^2)$ 降为"簇内 $O(n_c\cdot t_c)$ + 簇头 $O(l^2)$"；对 P8，去 TA/TEE；对 P7，簇头掉线容忍。代价：簇头选举与 resharing 协议复杂度；簇头比普通 UAV 多持一个 $R_q$ 份额。

## 方案五　BAND-HFL：簇内打包单密钥 + 跨簇 MKHE 合并 + 残差编码的带宽友好跨域层次 FL（层次型 FL 架构）

> **定位**：研究点 R5。多 UAV 跨区域协同（应急通信、森林防火、边境巡检）的硬约束是 **UAV-云链路带宽极稀缺**：若每架 UAV 的密文都直达云，链路随客户端数 $n$ 线性爆炸。本方案让 **UAV-云链路负载与客户端总数解耦（只与簇数 $L$ 成正比）**：簇内用打包单密钥 CKKS 把 $N_l$ 份密文聚成 1 份，跨簇在云侧用 CDKS 风格 MKHE 合并，silo 内 $(t_l,N_l)$-Shamir 保证无单点密钥。**本方案主打"验证联邦学习 + 隐私保护"的通信可行性**，属于隐私保护联邦学习在带宽约束下的结构优化。

### 5.1 场景

$L$ 个 UAV 编队（silo）分布在 $L$ 个空域，每 silo 含 $N_l$ 架 UAV 与一个簇头 UAV $E_l$。silo 内链路尚可（近距组网），**silo-云链路极度稀缺**（卫星链路 / 远距离地面站）。各 silo 之间无信任关系，也无常驻 TA；允许一次性离线 TA（或簇内 DKG）。要求：

- UAV-云上行流量 $\approx L$ 份密文，与 $\sum_l N_l$ 无关；
- 簇头 $E_l$ 只聚合不解密；
- silo 内抗掉线（$t_l$-out-of-$N_l$）与抗合谋；
- 跨 silo 聚合由云完成，云不掌握任何 silo 私钥。

### 5.2 要解决的问题（与最新研究的差距）

| 现有方案 | 已解决 | 未解决（本方案补齐） |
|---|---|---|
| P11 PPBR | 端-边-云隐私+鲁棒 | 每个边缘各自连云，跨域场景链路总数仍随客户端数增长；无跨 silo 密钥设计 |
| P6 FedPHE | 打包+稀疏+混淆 | 单 KDC、单密钥、单服务器，无跨 silo 能力 |
| P3 ResFed | 残差压缩 | 与 HE 正交但未联合设计；无隐私 |
| P2 CDKS | 多密钥同态 | 未用于"跨 silo 合并 + silo 内单密钥"的层次结构；无掉线容忍 |

**核心差距**：把三种正交技术**联合设计**而非简单叠加——① P6 式簇内打包单密钥 CKKS（silo 内便宜）；② P2 式 CDKS 多密钥加法（云侧跨 silo 合并）；③ P3 式残差编码（压缩 silo-云密文）。联合的关键洞察：**CDKS 的密文加法天然兼容"每个 silo 一个密钥"——silo 密文在云相加后，需全体 silo 的私钥共同解密，这正好强制 silo 间互不信任又必须协作**。

### 5.3 创新点 / 总体设计目标

1. **簇内打包单密钥 + 稀疏 + 混淆**：silo $l$ 共享 $\mathsf{pk}_l$，UAV 做 Top-$\rho$ 稀疏与零和混淆后加密，$E_l$ 把 $N_l$ 份密文聚成 1 份（CKKS 加法同态）。
2. **跨簇 MKHE 合并**：云把 $L$ 份 silo 密文按 CDKS 多密钥加法合并，合并密文需全体 silo 私钥联合才能解密。
3. **Silo 内 $(t_l,N_l)$-Shamir**：$\mathsf{sk}_l$ 分散在 silo 内 UAV，掉线 $N_l-t_l$ 仍可由在线 UAV 联合产生 silo 级部分解密。
4. **残差编码下传**：云对全局模型做预测残差编码（P3 思想）再下发，下行同样省带宽。
5. **严格优于 P11/P6/P3**：UAV-云带宽与客户端数解耦（P11 无）；跨 silo（P6 无）；压缩与 HE 联合（P3 无）。

### 5.4 威胁模型

- **簇头 $E_l$**：半诚实，**不解密**（只持 $\mathsf{pk}_l$ 做密文加法）；可与云合谋但仍无法单独解出 silo 明文。
- **云 $C$**：半诚实；可与 $\le t_l-1$ 个 silo-$l$ 客户端合谋，但无法获得 silo $l$ 的明文（除非该 silo 内 $\ge t_l$ 方合谋）。
- **silo 内客户端**：半诚实，合谋 $<t_l$；掉线 $\le N_l-t_l$。
- **跨 silo**：完全无信任，安全性纯由密码保证。
- **TA（可选）**：一次性离线生成各 silo 密钥对并 Shamir 分发后删除私钥；可用簇内 DKG（方案二）替代。
- **外部敌手**：RLWE 语义安全；认证信道；UAV 证书抗 Sybil。

### 5.6 方案设计：实体交互与闭环公式推导

**实体**：silo $l$ 内客户端 $C_{l,i}$、簇头 $E_l$；云 $C$；离线 TA。

#### 5.6.1 Setup（TA 一次性，或簇内 DKG）

TA 为每 silo 生成 $(\mathsf{sk}_l,\mathsf{pk}_l)$，把 $\mathsf{sk}_l$ 用 $(t_l,N_l)$-Shamir 拆给 silo $l$ 的 $N_l$ 个客户端（每客户端持份额 $s_{l,i}$，$\sum$ 插值得 $s_l$）；公开全部 $\mathsf{pk}_l$；删除私钥并离线。

#### 5.6.2 第 $r$ 轮训练

**步骤 1（silo 内：训练 + 稀疏 + 混淆 + 打包加密）**。$C_{l,i}$ 训练得 $w_{l,i}$，稀疏化 $\tilde w_{l,i}=\textsf{TopK}_\rho(w_{l,i})$，加零和混淆 $\sigma_{l,i}$（silo 内 DH 种子协商，$\sum_i\sigma_{l,i}=0$，同方案二）：
$$m_{l,i}=\Delta\cdot\textsf{Ecd}(\hat w_{l,i})\in R_q.$$
采样 $v_{l,i},e_{l,i,0},e_{l,i,1}$，用 $\mathsf{pk}_l$ 加密：
$$
c_{l,i,0}=v_{l,i}\,b_l+m_{l,i}+e_{l,i,0}\pmod q,\qquad c_{l,i,1}=v_{l,i}\,a+e_{l,i,1}\pmod q.
$$
相位：$c_{l,i,0}+c_{l,i,1}s_l=m_{l,i}+E_{l,i}\pmod q.$ CKKS 打包使单密文装 $N/2$ 维。
$C_{l,i}\to E_l$：$\mathsf{ct}_{l,i}$。

**步骤 2（簇头聚合，不解密）**。$E_l$ 只做加法：
$$\mathsf{ct}_l=\Bigl(C_{l,0},C_{l,1}\Bigr)=\Bigl(\sum_i c_{l,i,0},\ \sum_i c_{l,i,1}\Bigr)\pmod q,$$
$$C_{l,0}+C_{l,1}s_l=\sum_i m_{l,i}+\sum_iE_{l,i}=\Delta\,\textsf{Ecd}\Bigl(\sum_i\hat w_{l,i}\Bigr)+\sum_iE_{l,i}\pmod q,$$
混淆消去：$\sum_i\hat w_{l,i}=\sum_i\tilde w_{l,i}+\sum_i\sigma_{l,i}=\sum_i\tilde w_{l,i}.$

**步骤 3（silo-云上行：残差编码）**。$E_l$ 用共享预测器 $h_{\text{pred}}$ 对密文做残差压缩（P3 思想，在编码域量化 + Huffman），上云 $\delta_l$；云解码还原 $\mathsf{ct}_l$。**上行总量 $\approx L$ 份密文**。

**步骤 4（云侧跨 silo MKHE 合并）**。云按 CDKS 多密钥加法把 $L$ 份 silo 密文绑成一束（相位对全部 $(s_1,\dots,s_L)$ 成立）：
$$\Theta=\Bigl(C_0,\{C_{1}^{(l)}\}_{l=1}^L\Bigr),\qquad C_0=\sum_{l=1}^L C_{l,0}\pmod q,\quad C_{1}^{(l)}=C_{l,1},$$
$$
C_0+\sum_{l=1}^L C_{1}^{(l)}s_l=\sum_{l,i}m_{l,i}+\sum_{l,i}E_{l,i}\approx\Delta\,\textsf{Ecd}\Bigl(\sum_{l,i}\tilde w_{l,i}\Bigr)\pmod q. \tag{10}
$$

**步骤 5（silo 内联合部分解密）**。云向各 silo 在线客户端请求 silo 级部分解密。silo $l$ 内，在线客户端 $C_{l,i}$ 用份额 $s_{l,i}$ 计算：
$$\pi_{l,i}=C_{1}^{(l)}\cdot s_{l,i}+e_{l,i}'\pmod q,\quad e_{l,i}'\leftarrow\chi_e^{\text{pd}}.$$
silo 内按 $(t_l,N_l)$-Shamir 在本地（或经 $E_l$ 中转）插值聚合出 silo 级部分解密：
$$\Pi_l=C_{1}^{(l)}\cdot s_l+E_l\pmod q,\qquad \sum_{l=1}^L\Pi_l\approx\sum_l C_{1}^{(l)}s_l\pmod q. \tag{11}$$
（各 silo 的 $\Pi_l$ 由 silo 自己产生后发给云——云仍无法单独获得任何 $s_l$。）

**步骤 6（云全局解密 + 残差下传）**：
$$M=C_0+\sum_l\Pi_l\overset{(10)(11)}{\approx}\Delta\,\textsf{Ecd}\Bigl(\sum_{l,i}\tilde w_{l,i}\Bigr)\pmod q,$$
$$\bar w^t=\frac{1}{\sum_lN_l}\textsf{Dcd}\!\Bigl(\frac{M}{\Delta}\Bigr).$$
下行：$\delta^t=\bar w^t-h_{\text{pred}}(\bar w^{t-1})$ 编码后下发，客户端解码恢复。

#### 5.6.3 闭环公式链

$$
\boxed{
\begin{aligned}
&\textbf{密钥：}\ b_l=-as_l+e_l,\quad s_l=\sum_{i\in T_l}\lambda_i s_{l,i}\\
&\textbf{加密：}\ c_{l,i,0}+c_{l,i,1}s_l=\Delta\,\textsf{Ecd}(\tilde w_{l,i}+\sigma_{l,i})+E_{l,i}\\
&\textbf{簇聚合：}\ C_{l,0}+C_{l,1}s_l=\Delta\,\textsf{Ecd}(\textstyle\sum_i\tilde w_{l,i})+\sum_iE_{l,i}\quad(\sigma\text{ 消去})\\
&\textbf{跨簇合并：}\ C_0+\textstyle\sum_l C_{1}^{(l)}s_l=\Delta\,\textsf{Ecd}(\textstyle\sum_{l,i}\tilde w_{l,i})+\sum_{l,i}E_{l,i}\\
&\textbf{silo部分解密：}\ \Pi_l=C_{1}^{(l)}s_l+E_l\\
&\textbf{解密：}\ M=C_0+\sum_l\Pi_l\ \Rightarrow\ \bar w^t=\textsf{Dcd}(M/\Delta)/\textstyle\sum_lN_l
\end{aligned}}
$$

### 5.8 安全性分析

**定理 1（簇头不可解密）**。$E_l$（即使与云合谋）不能单独解出 silo $l$ 的聚合明文。
*证明要点*：$E_l$ 只持 $\mathsf{pk}_l$ 与密文分量之和；$\mathsf{sk}_l=s_l$ 以 $(t_l,N_l)$-Shamir 分散在 silo 内客户端，$\le t_l-1$ 份信息为 0；密文在 $\mathsf{pk}_l$ 下 IND-CPA（RLWE 归约）。$\blacksquare$

**定理 2（跨 silo 隐私）**。云与任意 silo 子集合谋（每 silo 内 $\le t_l-1$ 方）不能获得其它 silo 的明文更新。
*证明要点*：跨 silo 合并密文 $\Theta$ 的相位依赖**全部** $s_l$；缺失任一 $s_l$ 时，$C_0+\sum_{l'\ne l}C_{1}^{(l')}s_{l'}$ 与 $C_{1}^{(l)}s_l$ 在 RLWE 假设下不可区分（$C_{1}^{(l)}=C_{l,1}$ 是 RLWE 样本乘未知秘密），故 silo $l$ 的贡献对合谋者隐藏。$\blacksquare$

**定理 3（掉线容忍）**。silo $l$ 内 $N_l-t_l$ 个客户端掉线仍可产生 $\Pi_l$（Shamir 重构性质）；整个协议只需每 silo 至少 $t_l$ 个在线。
*证明要点*：直接由 $(t_l,N_l)$-Shamir 重构性质 + silo 内插值在本地完成（不经云）。$\blacksquare$

**定理 4（通信复杂度）**。UAV-云上行 = $O(L\cdot|R_q^2|)$，与客户端总数 $\sum_lN_l$ 无关；下行同理由残差编码压缩。
*证明要点*：步骤 2 把 $N_l$ 份密文聚成 1 份；步骤 3 残差编码在密文编码域操作不增加体积；故上行由 $L$ 决定。$\blacksquare$

**与现有方案的严格对比**：对 P11，跨 silo 且带宽与 $n$ 解耦；对 P6，跨 silo 协同 + 无 KDC 长期在线（TA 一次性）；对 P3，残差压缩与 HE 联合设计（密文域残差）而非正交叠加；对 P2，CDKS 从"通用多密钥推理"落到"跨 silo 层次聚合"的具体结构并补掉线容忍。代价：silo 内需要一次 Shamir 分发（Setup）；云需存储 $L$ 支密文（$O(L)$ 空间，通常 $L\ll n$ 可忽略）。

## 3.3 可组合性

五个方案是**正交积木**而非互斥选项：
- 方案二的**联合 DKG**可替换方案三/五的 KGA/TA（彻底去信任）；
- 方案一的**承诺抽查**可叠加到方案三/四/五的云侧（补可验证性）；
- 方案三的**边缘拜占庭过滤**可嵌入方案四的簇头、方案五的 $E_l$；
- 方案四的**resharing**可作为方案三边缘更换时的维护协议；
- 方案五的**残差编码**可用于所有方案的下行链路。

## 3.4 开放问题（下一步研究）

1. **恶意多数下的 MKHE 聚合**：五方案主要覆盖半诚实（除方案一的恶意服务器检测）。密文域拜占庭鲁棒聚合（同态范数裁剪/中位数/ZK 范围证明）仍是理论与工程双重挑战。
2. **形式化与实现**：IND-CPA 归约之外，需要 UC 框架下的可组合安全证明；基于 Lattigo/OpenMHE 的原型实现与 UAV 仿真链路（ns-3 + 真实丢包 trace）性能评估。
3. **能量-延迟联合优化**：把加密/通信开销纳入 MDP，在线学习"是否加密、是否担任簇头、阈值 $t$ 取值"。

5. **后量子认证**：RLWE 加密已后量子，认证仍靠 ECDSA；设计格基签名使整个系统在后量子威胁模型下自洽。
