## 1. 一句话概括

PPBR 是面向移动网络中**边缘辅助层次联邦学习（EHFL）**的"隐私保护 + 拜占庭鲁棒"混合方案：

- **边缘层**用 **CLDP（浓缩局部差分隐私）扰动后的符号统计 + trimmed k-means 聚类**过滤恶意**客户端**（算法 2, CC）；
- **云层**用 **PLHE（打包线性同态加密，BFV 方案）下的范数中位数筛选与裁剪**过滤/约束恶意**边缘节点**（算法 4 EF + 算法 5 GA）；
- 两层聚合均用 **SA（单服务器安全聚合，Bonawitz CCS'17 变体）+ 随机扰动**，保证服务器看不到明文本地/边缘模型。

三种原语缺一不可（Theorem 1）：无 CLDP → 聚类元组泄露本地模型信息；无 SA → 边缘/云可在聚合中重构个体动量；无 PLHE → 云在筛选时直接接触边缘模型明文。

## 2. 系统模型与实体

三层结构（云 — 边缘 — 客户端）：

| 实体 | 数量 | 职责 | 信任假设 |
|------|------|------|----------|
| 云服务器 A | 1 | 维护全局模型 w_a^(r)；选坐标子集 G 广播；广播 PLHE 公钥 pk_A；执行边缘级异常过滤（算法 4）、范数中位数计算、全局安全聚合（算法 5）并恢复全局模型 | **半诚实**（诚实执行协议但试图推断客户端数据分布） |
| 边缘服务器 A_i | l（路侧单元/微基站/宏基站） | 覆盖区内随机选客户端集合 U_i（\|U_i\|=n_i）；执行本地异常过滤（算法 2）、边缘安全聚合（算法 3，作为 SA 的"桶"） | **大多数半诚实，少数拜占庭**（可发任意更新、与客户端合谋） |
| 客户端 u_{i,j} | Σn_i = n（智能汽车/无人机/便携医疗设备） | 持有本地数据集 D_{i,j}（Non-IID），本地 SGD；生成符号统计元组、加 CLDP 噪声、加密随机噪声向量 | **大多数半诚实，少数拜占庭**（比例 β<0.5，可跨轮合谋优化攻击）；任意比例可能掉线 |

优化目标（分布式形式化）：

```
min_{w∈W} (1/n) Σ_{(i,j)} E_{ξ~D_{i,j}}[ ℓ(w, ξ) ]，  n = Σ_i n_i
```

D_{i,j} 与 D_{i',j'} 分布可不同（Non-IID）。

### 密钥持有情况（关键设计）

| 密钥 | 持有者 | 能解密什么 |
|------|--------|-----------|
| PLHE 云密钥对 (pk_A, sk_A) | sk_A 仅云持有 | 云可解密 [·]_A，**不能**解密 [·]_{A_i} |
| PLHE 边缘密钥对 (pk_{A_i}, sk_{A_i}) | sk_{A_i} 仅边缘 A_i 自己持有 | A_i 可解密自己的 [·]_{A_i}，不能解密别人的，也看不到客户端真实模型 |
| SA 客户端密钥 (sk_i, pk_i, b_i) | 客户端自生成；Shamir (t,n) 分片 | 无明文主密钥分发；掉线 < 阈值时可恢复掩码完成聚合 |
| CLDP 参数 (ε_χ, L, L') | 公开 | 无私钥 |

## 3. 威胁模型

- **隐私目标**：保护 ① 每个客户端的训练数据和本地模型更新的真实参数；② 每轮的边缘级模型（与本地模型相关）。系统内任何一方及任何合谋团体都不能从协议消息中推断目标客户端本地模型的真实参数。支持任意比例的客户端掉线。
- **拜占庭能力**：拜占庭客户端/边缘**偏离协议、任意轮发送任意更新**；比例 β<0.5；高级拜占庭者可**跨多轮合谋**、根据收集到的消息优化攻击（使恶意更新各维落入良性均值±标准差范围内，从距离/余弦视角难以检测）。
- **论文评估的 6 种攻击**：
  1. **Label flipping**：翻转每条样本标签；
  2. **Sign flipping**：梯度上升代替下降（梯度符号取反）；
  3. **Gaussian**：以高斯噪声作为更新；
  4. **ALIE**：对良性更新逐坐标算均值 μ_i、标准差 σ_i，令恶意更新落入 (μ_i − z_max·σ_i, μ_i + z_max·σ_i)，z_max 取自累积标准正态函数；
  5. **IPM**：β_in 个合谋拜占庭客户端设 ∇ℓ_1 = … = ∇ℓ_{β_in} = −ξ/(n_i−β_in) · Σ_{j=β_in+1}^{n_i} ∇ℓ_j，ξ 为幅度调节正因子；
  6. **MinMax**：调节 z_max 使恶意更新与任一良性更新的最大距离 ≤ 任意两个良性更新间的最大距离。

## 4. 加密设计（三原语混合）

### 4.1 CLDP（Condensed LDP）[Gursoy 2021]

传统 LDP 的推广：用**距离函数 d(s, s')** 取代多维预算分摊。定义（式 1）：

```
随机算法 M: X→R，对任意 s, s' ∈ X 和输出 y：
    f(y|s) ≤ e^{ε_χ · d(s, s')} · f(y|s')
```

隐私泄露水平由输入间距离调节。**PPBR 取 d(s, s') = ‖s − s'‖₂**。作用：把整个符号元组当作一个整体扰动（而不是逐维独立扰动），无需在维度间分摊隐私预算；有界支撑（L'）保证聚类精度。只用于边缘层过滤阶段客户端→边缘的 **3 维符号元组**。

扰动分布（式 2）：

```
f(y|s) =
  λ·e^(−ε_χ·‖y−s‖₂)              当 y ∈ B_L   （‖y−s‖₂ ≤ L）
  λ·e^(−ε_χ·L)                    当 y ∈ S_{L′}\B_L （L < ‖y−s‖₂ ≤ L′）
  0                               当 y ∉ S_{L′} （‖y−s‖_∞ > L′）

其中 S_{L′} = {y : ‖y−s‖_∞ ≤ L′}（超立方），B_L = {y : ‖y−s‖₂ ≤ L}（球）
归一化常数 λ = [B_L + e^{−ε_χ·L}·(2^d·L′^d − V_L)]^{−1}
  （V_L = π^{d/2}/(Γ(d/2)+1)·L^d 为 B_L 体积；原文 λ/B_L 精确表达式排版有乱码，
    按参考文献 [48]（Yang TIFS'22 的 d_χ-privacy k-means）标准结果重建）
```

### 4.2 PLHE（Packed Linearly Homomorphic Encryption，BFV 方案）

支持 SIMD 打包与同态加法 Add、密文-明文标量乘 Mult；**不需要密文×密文乘**：

```
KeyGen(1^k) → (pk, sk)
Enc(pk, m) → [m]
Dec(sk, [m]) → m
Add([m₁], [m₂]) = [m₁ + m₂]        （逐分量）
Mult([m], s) = [m · s]             （s 为明文标量/向量）
```

密文形态在各环节：

| 消息 | 加密密钥 | 说明 |
|------|----------|------|
| 客户端随机噪声 [x_{i,j}]_A | 云公钥 pk_A | 发给边缘，边缘同态求和后转云 |
| 边缘带噪动量 [2·m'_i]_{A_i} | **边缘自己的公钥**，云解不开 | 范数盲化计算用 |
| 边缘带噪动量范数平方 [‖m'_i‖₂²]_{A_i} | 边缘公钥 | 同上 |
| 边缘噪声和 [x_i]_A = Add({[x_{i,j}]_A}) | 云公钥 | 云解密后用于密文域恢复真实范数 |

**云在 [·]_{A_i} 密文上计算带噪范数平方，再用随机数 x'_i 盲化后送回边缘解密**——云全程不知道真实动量 m_i 和真实范数；边缘只能看到被 (x'_i)² 盲化后的范数平方，也不知道被用于筛选的具体值。

### 4.3 SA（单服务器安全聚合，Bonawitz CCS'17 变体）

基于 Shamir (t,n) 秘密共享 + κ-secure 密钥协商 S + PRG 的掩码协议。掩码公式（算法 1 第 4 行）：

```
z_i = m_i + x_i − Σ_{i'<i, C_{i'}∈U} υ_{i,i'} + Σ_{i<i', C_{i'}∈U} υ_{i',i}

其中 υ_{i,i'} = PRG(S(sk_i, pk_{i'}))  客户端对间的成对掩码（双向约定使总和抵消）
      x_i = PRG(b_i)                   被 Shamir 分成 n 份（阈值 t）
```

聚合服务器算出掉线集 U^(d) 和幸存集 U^(s)（|U^(s)| < t 则中止），恢复 x_i 并令幸存客户端协作恢复与掉线者相关的掩码和 V_i、V'_i，最后：

```
m = (Σ_{C_i∈U^(s)} (z_i − x_i + V_i − V'_i)) / |U^(s)| = (Σ m_i) / |U^(s)|
```

SA 明文运行，但输入是**已加随机扰动的带噪动量**，所以服务器只见均值。

### 4.4 谁能否解密（小结）

- 边缘 A_i：能解密 [·]_{A_i}（自己的 sk_{A_i}）；看不到客户端真实本地模型（输入是带噪动量且经 SA 掩码，只有均值）。
- 云 A：能解密 [·]_A；**不能**解密 [·]_{A_i}；通过 SA + 去噪得到的是聚合均值，不是单个边缘模型。
- 客户端：不持有任何服务器私钥。

## 5. 核心算法逐条细节

初始化时云广播：隐私预算 ε_χ、参数 λ、距离阈值 L 和 L'、全局聚合掉线阈值 t、动量参数 φ 和 ζ、范数筛选阈值 θ、坐标子集 G、全局模型 w_a^(r)、pk_A；边缘设自己覆盖区的客户端掉线阈值 t_i。

默认超参数：**k = 2, b = 1**（沿用 [17]）；**l = 8, L = 6, L′ = 7**（按 [48] 控制 CLDP 精度损失）；**φ = 0.9, ζ = 0.0125**（按 [15] bucketing 收敛分析）；**β = 0.3**，α = 0.5（Non-IID Dirichlet 参数）。

### 5.1 算法 2（CC）：CLDP 聚类过滤边缘层恶意客户端

**a) 生成符号向量**：云先选出 ι 个随机坐标 G 广播。每个客户端 u_{i,j} 只在这 ι 个坐标上统计符号，生成**符号统计元组**（引用 Xu ICDCS'22 的符号统计思想）：

```
s_{i,j} = (正号比例, 负号比例, 零号比例) ∈ R³，  d = 3
```

这是保留梯度方向性的轻量特征。

**b) CLDP 扰动**：客户端从式 (2) 分布采样扰动后的 y_{i,j}（见 §4.1）。

**c) Trimmed k-means 聚类 + 过滤**：客户端把 3 维带噪符号元组 y_{i,j} 发给边缘 A_i；A_i 执行 **trimmed k-means** [Dorabiala 2021] 得到簇 C_i = {C_1, …, C_k}。然后 A_i 取**尺寸最大的前 b 个簇**中的客户端构成可信集 U_i^(T)，|U_i^(T)| = n'_i。

直觉：良性客户端梯度方向相似 → 聚成大簇；恶意客户端方向发散 → 落在小簇。最简单的情形 b = 1, k = 2：分成两簇，取较大簇。

### 5.2 算法 3（EA）：隐私感知边缘聚合

1. 每个幸存可信客户端 u_{i,j} ∈ U_i^(T)：
   - 生成秘密随机向量 x_{i,j} ∈ Z^m；
   - 计算动量：**m_{i,j} = φ·m_{i,j} + (1−φ)·w_{i,j}**（φ 为动量系数，默认 0.9）；
   - 带噪动量：**m'_{i,j} = m_{i,j} − x_{i,j}**；
   - 用 pk_A 加密 [x_{i,j}]_A 发给 A_i。
2. A_i 作为桶，对带噪动量执行 SA（阈值 t_i，容忍客户端掉线）：

   ```
   m'_i ← SA({m'_{i,j}}_{u_{i,j}∈U_i^(T)}, t_i)     —— 带噪动量的均值
   ```

   边缘**看不到任何单个客户端的真实动量**，只看到带噪均值。
3. A_i 同态求和 **[x_i]_A = Add({[x_{i,j}]_A})**，并把三个消息发给云：

   ```
   [2·m'_i]_{A_i}，  [‖m'_i‖₂²]_{A_i}，  [x_i]_A
   ```

### 5.3 算法 4（EF）：范数中位数筛选（云层过滤恶意边缘）

目标：云在不获知真实边缘动量的情况下算出各边缘动量的 L2 范数、取中位数 M，并筛掉偏离中位数超过 θ 的边缘。

1. 云初始化 A^(T) = ∅。
2. 云解密 [x_i]_A 得 x_i，然后**纯密文运算**（Add + 密文×明文 Mult）：

   ```
   [‖m_i‖₂²]_{A_i} = Add( [‖m'_i‖₂²]_{A_i},
                         [x_i²]_{A_i},
                         Mult([2·m'_i]_{A_i}, x_i) )
   ```

   成立因为 m = m' + x ⇒ ‖m‖² = ‖m'‖² + ‖x‖² + 2·m'·x（点积即 Mult 后 Add）。
   再用随机数 x'_i ∈ Z 盲化：Mult 得 **[(x'_i)²·‖m_i‖₂²]_{A_i}**，发给 A_i。
3. A_i 用自己的 sk_{A_i} 解密得 (x'_i)²·‖m_i‖²，**开方后**回传 **[√((x'_i)²‖m_i‖²)]_A**（原文此处开方/取整符号模糊，按上下文推断为先开方再加密回传，使云得到 ‖m_i‖₂）。**云只知道范数不知道 m_i 本身；边缘只知道自己被盲化的范数，不知道阈值比较过程**。
4. 云把所有幸存边缘放入 A^(T)。
5. 云计算范数中位数 **M = median({‖m_i‖₂})**。
6. 云删除不满足 **‖m_i‖₂ ∈ [M − θ, M + θ]** 的 A_i，直到：

   ```
   |A^(T)| = l' = min{(1−β)l, l_s}    （已知 β 时）
          或 min{0.5·l, l_s}           （未知 β 时）
   ```

   l_s 为幸存边缘数，θ 是可调阈值。**关键性质：PPBR 不需要事先知道拜占庭比例**（未知时用 0.5l）。

### 5.4 算法 5（GA）：范数中位数裁剪 + 全局聚合

1. 对满足 ‖m_i‖₂ ≥ M 的边缘，云把 [x'_i·M]_{A_i} 发回并设 **x''_i = M / ‖m_i‖₂**；其余边缘设 x''_i = 1。（用随机数 x'_i 做掩护，使送回边缘的密文不泄露 M/‖m_i‖₂ 的比值明文——边缘解密拿到 x'_i·M，与自己已知的 (x'_i·‖m_i‖) 相除才能凑出裁剪系数。）
2. 收到密文的边缘计算裁剪后的带噪动量：

   ```
   m''_i = (x'_i·M) / (x'_i·‖m_i‖₂) · m'_i = min(1, M/‖m_i‖₂) · m'_i
   ```

   其余边缘 m''_i = m'_i。效果：真实动量被裁到范数 ≤ M。
3. 云与 A^(T) 中的边缘执行 SA（阈值 t，容忍边缘掉线）：

   ```
   m''_a ← SA({m''_i}_{A_i∈A^(T)}, t)
   ```
4. 云去噪得到真实平均动量：

   ```
   m_a = m''_a + Σ_{A_i∈A^(T)} x''_i · x_i
   ```

   （因为每个 m''_i = x''_i·(m_i − x_i)，均值后加回 Σx''_i·x_i 即得 Σx''_i·m_i 的均值。）
5. 云更新全局模型：**w_a ← w_a − ζ·m_a**（ζ 为全局步长，默认 0.0125）。

### 5.5 掉线/异步容忍

- **客户端掉线**：边缘聚合 SA 用 Shamir 阈值 t_i；只要幸存客户端 |U^(s)| ≥ t_i 即可恢复掉线者掩码完成聚合，否则该轮中止。任意掉线比例均可容忍（低于阈值才中止）。
- **边缘掉线**：全局聚合 SA 用阈值 t；全局聚合结果在少于 l′ − t 个边缘掉线时可获得（Lemma 4）。
- 掉线在 SA 的 Unmasking 阶段处理：聚合服务器公布掉线集 U^(d)，幸存客户端恢复与掉线者配对的掩码和。

## 6. 一轮训练的实体交互时序（完整消息流）

设当前为第 r 轮，全局模型 w_a^(r)：

| # | 方向 | 消息 | 对应算法 |
|---|------|------|----------|
| 1 | 云 → 所有边缘 + 被选客户端 | 广播 ε_χ, λ, L, L′, t, φ, ζ, θ、坐标子集 G、w_a^(r)、pk_A | 初始化 |
| 2 | 边缘 → 覆盖区客户端 | 分发全局模型 | EHFL 工作流 |
| 3 | 客户端本地 | w_{i,j} = w_a − η·∇ℓ(w_a, D_{i,j})，本地 20 步 SGD | — |
| 4 | 客户端 → 边缘 A_i | 3 维 CLDP 带噪符号元组 y_{i,j} | 算法 2 第 3 行 |
| 5 | 边缘 A_i | trimmed k-means 聚类 → 取 top-b 大簇构成可信集 U_i^(T) | 算法 2 |
| 6 | 客户端 ↔ 边缘 + 客户端间（经边缘中转） | SA：密钥交换、密文份额交换、掩码 z_{i,j} | 算法 1/3 |
| 7 | 客户端 → 边缘 | 掩码后的带噪动量 z；以及 [x_{i,j}]_A | 算法 3 |
| 8 | 边缘 → 云 | ① [2·m'_i]_{A_i}；② [‖m'_i‖²]_{A_i}；③ [x_i]_A = Add(所有 [x_{i,j}]_A) | 算法 3 |
| 9 | 云 → 边缘 | [(x'_i)²·‖m_i‖²]_{A_i}（x'_i 为云的随机盲化数） | 算法 4 |
| 10 | 边缘 → 云 | 解密开方后再加密回传 [‖m_i‖₂]_A | 算法 4 |
| 11 | 云 | 算所有边缘范数的中位数 M，按 [M−θ, M+θ] 筛选得 A^(T) | 算法 4 |
| 12 | 云 → 需裁剪的边缘 | [x'_i·M]_{A_i} | 算法 5 |
| 13 | 边缘 | 解密并自裁剪 m''_i = (x'_i·M)/(x'_i·‖m_i‖)·m'_i | 算法 5 |
| 14 | 边缘 ↔ 云（+ 边缘间经云中转） | SA：掩码后的 m''_i 发给云 | 算法 5 |
| 15 | 云 | 去噪 m_a = m''_a + Σ x''_i·x_i，更新 w_a ← w_a − ζ·m_a | 算法 5 |

聚合层数：**两层平均聚合**（边缘内均值 + 边缘间均值），权重均为均匀 1/n'_i 和 1/l′（裁剪后按 x''_i 加权）。

## 7. 安全性与隐私分析（关键结论）

- **Lemma 1**：算法 2 满足 ε_χ-CLDP（式 1）。攻击者难以从扰动元组推断真实符号统计，进而无法推断本地模型（符号可泄露真实标签）。
- **Lemma 2**：算法 3 中，对每边缘 A_i，客户端本地模型真实参数可抵抗至多 t'_i < n'_i − 1 方的合谋；且掉线客户端数 < n'_i − t_i 时仍可得边缘聚合结果。
- **Lemma 3**：若 PLHE 语义安全，算法 4 能安全地检测并过滤异常边缘模型（云在筛选全程不接触真实动量）。
- **Lemma 4**：算法 5 中，边缘级模型真实参数可抵抗至多 t' < l′ − 1 方的合谋（对云 A 而言）；掉线边缘 < l′ − t 时仍可得全局聚合结果。
- **Theorem 1**：由引理 1–4，PPBR 达到隐私目标。三者（CLDP/SA/PLHE）缺一不可。
- **Theorem 2**（CLDP 对聚类精度的影响）：对任意簇 C_κ，真实质心 s_κ、扰动质心 y_κ，则 y_κ **无偏**（E(y_κ) = s_κ），且：

  ```
  E(‖y_κ − s_κ‖₂²) ≤ 3L²(e^{ε_χ·c_L} − 1) / [5·|C_κ|·(e^{ε_χ·c_L} + 1)] + L²/|C_κ|   （d=3 代入）
  ```

  误差随簇增大而缩小、随 L 与 ε_χ 调大而受控。证明思路：扰动分布关于 s 旋转对称，一阶误差期望为 0；二阶界引用 [48] 的 Lemma 4。

## 8. 实验设置与主要结论

**实现**：Python + PyTorch；PLHE 用 TenSEAL（Microsoft SEAL）；BFV，SIMD 槽数 2048，128-bit 安全级；PRG 用 AES、密钥协商用 Diffie-Hellman；双 Xeon Silver 4210R + RTX 3090 + 512GB RAM。

**数据与模型**：MNIST + MLP（batch 32）；Fashion-MNIST + CNN 3 卷积 + 2 全连接（batch 64）；60,000 训练 / 10,000 测试；SGD，全局 lr 1.0、本地 lr 0.01；每客户端本地 20 步；IID / Non-IID（Dirichlet α，α 越小越 Non-IID）分别 200 轮 FedAvg 和 2000 轮 FedSGD；240 个客户端；结果取 10–20 次运行均值。

**Baselines**：Median、TrimmedMean、GeoMed、Multi-Krum、DnC、CenteredClipping（均**无 LDP 噪声**，即 PPBR 在加噪的不利条件下对比）。

**主要结论**（Table IV 逐攻击精度矩阵、Fig. 3–6 曲线为图片，文本提取缺失；以下为正文数字）：

- 理论最优（IID 无攻击 Mean 聚合）：MNIST 95.66%，F-MNIST 88.13%；PPBR 在 α=0.5、β=30% 下所有攻击的精度最接近该值。
- DnC 与 PPBR 最强；PPBR 在所有攻击下精度高于 DnC，尤其 F-MNIST 上抗 ALIE。
- CenteredClipping 在 β=40% 高斯攻击下精度跌至约 10%（≈随机猜测）。
- Non-IID（α=0.1, β=40%）下 Median 精度降 3.60%，Multi-Krum 降 2.06%；PPBR 精度下降最少。
- PPBR 在 label flipping 下甚至超过无攻击 FedAvg（过滤异常更新抑制过拟合的"意外正效应"）。
- 聚类有效性（Fig. 7）：算法 2 选出的良性客户端比例在所有隐私预算下高于 k-means/层次/谱聚类 × RR/GRR/OLH 的组合；ε_χ ≥ 3 时 >80% 良性模型被选中参与聚合。
- 隐私参数影响（Fig. 8/9）：每边缘客户端数 > 40 且 ε_χ > 10 时精度接近最优；高异构（α=0.1）下 ε_χ ≥ 4 仍高精度，ε_χ ≥ 7 时精度 > 85%（sign flipping, β=40%）。

**开销**（Tables V–VI 逐操作数值为表格提取缺失，正文数字如下）：

- 客户端每轮计算 < 0.5 s；PLHE 密文通信每轮 MNIST 36.39 MB、F-MNIST 133.22 MB；5G 下传输仅 0.6 s / 2.1 s。
- 云 PLHE 额外计算随边缘数线性增长，l = 6 时每轮 < 10 s。
- CC 开销：客户端计算/通信 O(d)，d=3；边缘计算 O(I·n_i·k·d)，通信 O(n_i·d)。
- SA 开销：客户端 O(n′_i² + n′_i·m) 计算、O(n′_i + m) 通信；边缘 O(n′_i²·m) 计算。引 [6] 实测：n′_i=500、m=100k 时客户端 13.159 s / 0.95 MB，边缘 14.670 s（无掉线）、62.239 s（10% 掉线）。全局侧每个边缘 O(l′² + l′m) 计算，云 O(l′²m)。
- Non-IID 对收敛影响（Fig. 10）：α=0.5 时 MNIST 约多 5 轮、F-MNIST 约多 200 轮收敛到 IID 同等精度。
- 收敛（Fig. 11）：α=1.0、label flipping、β=0.3 下 PPBR 收敛速度与 baselines 相当或更快且精度最高。
