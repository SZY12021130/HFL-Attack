## 一、【步骤 1】总体框架闭环公式推导与正确性校验

### 1.1 符号系统

| 符号 | 含义 |
| :--- | :--- |
| 𝐾、𝑀′、𝐵 | 稀疏块长（如 256）、内层环维（如 4096）、折叠块数 𝐵 = ⌊𝑀′/𝐾⌋（如 16） |
| 𝑆_outer、𝑆^(𝑚)、𝑠_{m,i} | 外层总私钥（簇间加性拆分）、簇子钥、(𝑡ₘ,𝑛ₘ)-Shamir 份额 |
| 𝑏_{m,i,𝛽}、𝑛_{m,i,𝛽} | 第 𝛽 块外层份额 𝑏 = 𝑐_{𝛽,1}·𝑠_{m,i}、混淆噪声块 |

### 1.2 创新点

1. **SlotFoldWeld**：单项式正交折叠（一次内层双密钥解开 𝐵 块），直击 ATASSES 短向量退化（𝐾 < 𝑀′ 时 93.75% 槽位空置）。
2. **HuberWeightHE**：平滑 Huber 鲁棒权重（免硬截断震荡）+ 残差补偿稀疏。
3. 双轨焊接 dk = 𝑆₁+𝑆₂ + LHH/BLS 可验证。

### 1.3 主线闭环推导（展开）

**（1）折叠的正交性（核心）——在"次数 < 𝐾"前提下正确 ✅。**

  𝐁_{m,i}(𝑋) = ∑_{𝛽=0}^{𝐵−1} 𝑋^{𝛽𝐾}·𝑏_{m,i,𝛽}(𝑋) = ∑_𝛽 ∑_{𝑢=0}^{𝐾−1} 𝑏_{m,i,𝛽}[𝑢]·𝑋^{𝛽𝐾+𝑢}

各块非零系数严格落在互不相交区间 [𝛽𝐾, (𝛽+1)𝐾−1]，且 𝐵·𝐾 ≤ 𝑀′ ⇒ 无 𝑋^{𝑀′} = −1 环绕。✅

**（2）标量 𝐿 不跨块串扰。** 𝐿_{m,i} ∈ ℤ_𝑞 为零次常数：

  𝐿·𝐁 = ∑_𝛽 𝑋^{𝛽𝐾}·(𝐿·𝑏_{m,i,𝛽})  ✅ 不改变次数，块间正交保持。

**（3）双轨封装与焊接（同方案 1 机制）。**

  𝑐′_{b,m,i,0} = (𝑎′ₘ·𝑒𝑘_{m,i,1})·𝑢′ₘ + Δ′·𝐁_{m,i} + 𝑒′_{m,i,1} (mod 𝑄′)
  𝑐′_{n,m,i,0} = (𝑎′ₘ·𝑒𝑘_{m,i,2})·𝑢′ₘ + Δ′·𝐍_{m,i} + 𝑒′_{m,i,2} (mod 𝑄′)

  𝐶′ₐₗₗ,m,0 = ∑ᵢ (𝐿_{m,i}·𝑐′_{b,m,i,0} + 𝑐′_{n,m,i,0})
            = (𝑎′ₘ𝑢′ₘ)·(𝑆_{m,1}+𝑆_{m,2}) + Δ′·∑_𝛽 𝑋^{𝛽𝐾}·(∑ᵢ𝐿ᵢ𝑏_{i,𝛽} + ∑ᵢ𝑛_{i,𝛽}) + 𝐸′

  其中 ∑ᵢ𝐿ᵢ𝑏_{i,𝛽} = 𝑐_{𝛽,1}·𝑆^(𝑚) ✅（拉格朗日恒等式）。

**（4）脱壳与拆包。**

  𝐁′ₘ = ⌊(𝐶′ₐₗₗ,m,0 + (−𝑎′ₘ𝑢′ₘ)·dkₘ)/Δ′⌉ = ∑_𝛽 𝑋^{𝛽𝐾}·(𝑐_{𝛽,1}𝑆^(𝑚) + 𝑁_sm,𝛽)  ✅
  GBS 按次数区间提取 𝑏′_{m,𝛽}，跨簇求和后外层取整：
  𝑀_𝛽 = ⌊(𝑐_{𝛽,0} + ∑ₘ 𝑏′_{m,𝛽})/Δ⌉，因为 ∑ₘ𝑏′_{m,𝛽} = 𝑐_{𝛽,1}·𝑆_outer + ∑𝑁 ✅ 与 𝑐_{𝛽,0}+𝑐_{𝛽,1}𝑆_outer = Δ·𝑀_𝛽 + 𝑒_𝐶𝑇 吻合。

**（5）但"次数 < 𝐾"前提本身不成立 ❌（致命断点）：**

  𝑏_{m,i,𝛽}(𝑋) = 𝑐_{𝛽,1}(𝑋)·𝑠_{m,i}(𝑋) (mod 𝑄)

  外层密文第二项 𝑐_{𝛽,1} 与份额 𝑠_{m,i} 均为环元素（次数可至 𝑀−1 或由块定义）。乘积次数 = deg(𝑐_{𝛽,1}) + deg(𝑠_{m,i})，**一般远超 𝐾−1**；若不显式在 ℛ_{𝐾,𝑞} = ℤ_𝑞[𝑋]/(𝑋^𝐾+1) 中做块级乘法（或对 𝑏 约化 mod 𝑋^𝐾），则 𝑏 的高次系数将溢出到相邻折叠区间，产生**跨块串扰**，定理 4.1 的正交性失效、拆包取块错误。

### 1.4 步骤 1 结论：闭环条件性通过 → 问题清单

| 排序 | 问题 | 严重度 | 解决（重要度） |
| :--- | :--- | :--- | :--- |

## 三、【步骤 3】数学算例闭环

### 3.1 折叠正交性正例（𝐾 = 2、𝑀′ = 4、𝐵 = 2）

  𝑏₀ = 1+2𝑋（deg 1 < 2 ✅）、𝑏₁ = 3+𝑋
  𝐁(𝑋) = 𝑏₀ + 𝑋²·𝑏₁ = 1+2𝑋 + 3𝑋²+𝑋³（次数区间 [0,1] ∪ [2,3] 无交叠 ✅）
  拉格朗日标量 𝐿 = 5：5·𝐁 = 5+10𝑋+15𝑋²+5𝑋³（各块独立放大 ✅ 无串扰）
  拆包：区间 [2,3] 提取 (3,1) = 𝑏₁ ✅

### 3.2 P1 反例：份额次数溢出 ⇒ 跨块串扰

设块环未独立化：𝑠 = 1+𝑋+𝑋²（deg 2）、𝑐₁ = 1+𝑋（deg 1）：
  𝑏 = 𝑐₁·𝑠 = (1+𝑋)(1+𝑋+𝑋²) = 1+2𝑋+2𝑋²+𝑋³（deg 3 > 𝐾−1 = 1 ❌）
  折叠两块（假设 𝑏₀ 如上、𝑏₁ = 1+2𝑋+2𝑋²+𝑋³）：𝑋²·𝑏₁ 的次数达 5 > 𝑀′−1 = 3 ⇒ 环绕 𝑋⁴ = −1 回卷到低次区间，块 0/块 1 混叠，拆包出错。**实证 P1。**
  修复（块级环）：在 ℤ_𝑞[𝑋]/(𝑋²+1) 中 𝑏 = (1+𝑋)(1+𝑋+X² mod 𝑋²+1) = (1+𝑋)·(0+2𝑋) = … deg < 2 恒成立 ✅ 折叠正交性恢复。

### 3.3 双轨焊接脱壳算例

沿用方案 1 数值（块级标量化）：𝑏_{1,𝛽} = 2、𝑏_{2,𝛽} = 3、𝐿 = (2, −1)、𝑛 = (2, −1)：
  ∑𝐿ᵢ𝑏ᵢ + ∑𝑛ᵢ = (4−3) + 1 = 2 = 𝑐₁𝑆 + 𝑁_sm 形态 ✅；外层 ⌊(𝑐₀ + ∑ₘ𝑏′)/Δ⌉ 取整恢复 ✅（与方案 1 算例同构）。

### 3.4 Huber 权重算例

  𝛿 = 1：𝑟 = 0.5 ⇒ 𝑤 = 1；𝑟 = 2 ⇒ 𝑤 = 0.5；𝑟 = 10 ⇒ 𝑤 = 0.1（平滑衰减，无硬截断断点 ✅）

## 五、【步骤 5】鲁棒性功能（HuberWeightHE）单独深检

### 5.1 介绍

本地：𝑉 = 𝑝Δ𝑤 + 𝑌（残差池），切块选 Top-𝐵 活跃块加密；LRU：对块与动量中心偏差范数 𝑟 = ‖𝑀 − 𝑀_mom‖₂ 施加平滑 Huber 权重 𝑤 = 1（𝑟 ≤ 𝛿）或 𝛿/𝑟，定点化加权聚合。

### 5.2 闭环推导（展开）

1. 残差补偿：未选中块 𝑌^(𝑡+1) = 𝐠^(𝑡) 回存 ⇒ 稀疏误差不消失、仅延迟（累积补偿正确 ✅，与 FedPHE/Ftopk 同）。
2. Huber 影响函数：目标 min ∑Huber(‖𝑥ᵢ−𝑥‖)；最优权重 ∝ 𝜓(𝑟)/𝑟，其中 𝜓(𝑟) = 𝑟（𝑟≤𝛿）、𝛿·sign(𝑟)（𝑟>𝛿）⇒ 𝑤 = 1 或 𝛿/𝑟 ✅ 与 AAAI'24 影响函数形式一致。
3. 平滑性：𝑤(𝑟) 在 𝑟 = 𝛿 处连续（1 = 𝛿/𝛿）✅，无硬截断震荡。
4. 加权同态：𝑊 = ⌊Δ_w·𝑤⌉ 明文乘密文 ✅。

### 5.3 模块算例

见 3.4；再验连续性：𝑟 → 𝛿⁻ 时 𝑤 = 1，𝑟 → 𝛿⁺ 时 𝑤 = 𝛿/𝛿 = 1 ✅。
对抗性：投毒块 𝑟 = 100·𝛿 ⇒ 𝑤 = 0.01，影响被压制 100 倍 ✅；稀有良性块 𝑟 = 2𝛿 ⇒ 𝑤 = 0.5（仍参与，优于硬截断归零）✅。

### 5.4 模块问题与安全

- P2 距离泄露（LRU 见 𝑟）；动量中心 𝑀_mom 若为明文则 LRU 可反推个体块结构——建议动量中心也密态维护。

- 非凸深度网络上 Huber 理论界（AAAI'24 为凸/非凸弱条件）需实验背书。

## 六、【步骤 6】可验证性功能单独深检

### 6.1 介绍

分块标签 τ_{m,i,𝛽} = LHH(𝑀_{m,i,𝛽}) + BLS；聚合 𝒯_glob,𝛽 = ∏(τ)^{𝑊}；客户端核验 LHH(𝑀_𝛽) ≟ 𝒯_glob,𝛽。

### 6.2 闭环推导

  若权重 𝑊 进指数：同方案 2 P1 的整数域问题复现 ⚠️（𝑊_{m,i} 加权时 ∑𝑊⌊Δ𝑀⌉ ≠ ⌊Δ∑𝑊𝑀⌉）。

  - 或客户端重新加权验证（需知 𝑊 与个体标签——可得）✅ 推荐整数域式。

  防漏加/篡改：BLS 锁定个体标签 ✅；折叠/拆包过程的块对应关系由次数区间保证（P1 修复后）✅。
