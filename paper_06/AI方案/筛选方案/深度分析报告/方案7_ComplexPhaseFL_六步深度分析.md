## 一、【步骤 1】总体框架闭环公式推导与正确性校验

### 1.1 符号系统

| 符号 | 含义 |
| :--- | :--- |
| 𝑔ᵢ ∈ ℝ^𝑀、𝑧ᵢ ∈ ℂ^{𝑀/2} | 实数梯度；奇偶配对复梯度 𝑧_{i,𝑢} = 𝑔_{i,2𝑢−1} + 𝑗·𝑔_{i,2𝑢} |
| 𝜃_{i,𝑢}、𝑤_{i,𝑢} = 𝑒^{𝑗𝜃} | 子块极角 atan2(𝑔_{2𝑢}, 𝑔_{2𝑢−1})；单位模欧拉相位 |
| 𝜎⁻¹、𝜎、Conj | CKKS 逆正则嵌入/解码/共轭自同构（𝑋 ↦ −𝑋^{𝑀−1}） |

| 𝑆、𝑠ᵢ、𝑒𝑘ᵢ,₁、𝑒𝑘ᵢ,₂、𝑆₁、𝑆₂、dk | 外层门限密钥与双钥组合（同方案 1） |

### 1.2 创新点

1. **复数同构打包**：实梯度奇偶配对入 ℂ^{𝑀/2}，单密文实参数容量 𝑀/2 → 𝑀（×2）。
2. **厄米特相位余弦**：Re(𝑤ᵢ·𝑤̄_ref) = cos(𝜃ᵢ − 𝜃_ref)，免除法、免开方、免密文乘法、免重缩放。
3. **OneShotComplexDec**：同维双钥单轮组合 + 承诺防伪 + CKKS 解码实虚部拆包。
4. 免重缩放噪声线性界 + 闭式收敛界 ‖𝑤^(𝜁) − 𝑤*‖ ≤ (1−𝜂μ)^𝜁‖𝑤⁰−𝑤*‖ + 𝜀_enc/μ。

### 1.3 主线闭环推导（展开）

**（1）复数同构打包。** 𝑧_{i,𝑢} = 𝑔_{i,2𝑢−1} + 𝑗·𝑔_{i,2𝑢}，𝑢 = 1..𝑀/2：
  - 编码 𝑚_{z,i} = ⌊Δ·𝜎⁻¹(𝑧ᵢ)⌉ ∈ ℛₘ,𝑞 → 加密 (𝑐_{z,i,0}, 𝑐_{z,i,1})。✅ 一个复槽承载两个实数，容量翻倍（对照实数嵌入虚部置零的浪费）——**数学正确**。

**（2）欧拉相位编码。** 𝑤_{i,𝑢} = 𝑒^{𝑗𝜃_{i,𝑢}} = cos𝜃 + 𝑗sin𝜃，\|𝑤\| = √(cos²+sin²) = 1 ✅ 恒等式成立。

**（3）厄米特内积取实（核心）——逐项展开验证：**

  𝑐̂_cos,i = ½·( 𝑃_conj ⊙ ŵᵢ ⊕ Conj(𝑃_conj ⊙ ŵᵢ) )

  第 𝑢 槽：𝑃_conj 槽值 = 𝑒^{−𝑗𝜃_ref,𝑢}，ŵᵢ 槽值 = 𝑒^{𝑗𝜃_{i,𝑢}}：
  乘积 = 𝑒^{𝑗(𝜃_{i,𝑢} − 𝜃_ref,𝑢)}；共轭 = 𝑒^{−𝑗(𝜃_{i,𝑢} − 𝜃_ref,𝑢)}
  ½(两者之和) = cos(𝜃_{i,𝑢} − 𝜃_ref,𝑢) ✅ **恒等式精确成立。**

**（4）"免重缩放"性质。** 全程仅明文-密文乘（𝑃_conj 明文）+ 共轭自同构（线性）+ 加法 ⇒ 噪声线性累积 𝜂_total = 𝜂_scalar + 𝜂_add + 𝜂_thresh ≤ 𝜂_bound，无需模数链 ✅ **正确**（26-PPDO 的噪声定理适用）。

**（5）打分与过滤。** 𝒞̄ᵢ = (2/𝑀)·∑_𝑢 cos(𝜃_{i,𝑢} − 𝜃_ref,𝑢)；MAD 阈值截尾。⚠️ **声明精度问题**：𝒞̄ᵢ 是"逐对（2 维）相位余弦的均值"，对单个 2 维对它确是该对向量的精确余弦；但对整条 𝑀 维梯度向量，它**不等于** d 维余弦 cos(𝐠ᵢ, 𝐠_ref)（d 维余弦含范数权重与交叉项）。作为相似度打分合理（元素级方向一致性均值），但"精确的块级余弦"应改述为"逐对相位余弦均值"——**P5（低-中，声明精度）**。

**（6）同维双钥组合解密。** 与方案 1 完全同构：
  𝐶′ₐₗₗ,₀ = ∑(𝐿ᵢ·𝑐′_{b,i,0} + 𝑐′_{n,i,0}) = (𝑎′𝑢′)(𝑆₁+𝑆₂) + 𝑐₁𝑆 + ∑𝑛ᵢ ✅
  𝑏′ = 𝐶′ₐₗₗ,₀ + (−𝑎′𝑢′)·dk = 𝑐₁𝑆 + ∑𝑛ᵢ ✅
  𝑚′ = 𝑐₀ + 𝑏′ = Δ·𝑀_glob(X) + 𝜂_hom + 𝜖_thresh；CKKS 解码 𝑧_glob = 𝜎(𝑚′/Δ)；拆包 𝑔_{2𝑢−1} = Re、𝑔_{2𝑢} = Im ✅ **闭环正确。**

**（7）承诺检验——与方案 1 相同的致命 bug ❌：**
  𝑔^(𝑐′_{b,i,0}(𝑧_cₕₖ)) ≟ 𝑀_{i,1}·(𝑉𝐾ᵢ)^(𝑐₁(𝑧_cₕₖ)) 在商环中不成立（求值非环同态），除非 𝑧^𝑀 ≡ −1 (mod 𝑄)。**P1 = 方案 1 P1 同源**。

### 1.4 步骤 1 结论：主线闭环（除承诺）通过 → 问题清单

| 排序 | 问题 | 严重度 | 解决（重要度） |
| :--- | :--- | :--- | :--- |
| **P1** | 承诺检验等式商环不成立（同方案 1） | **致命（验证不可用）** | 同方案 1：𝑧^𝑀 ≡ −1 或系数向量内积承诺 |
| **P2** | 余弦打分语义：逐对相位余弦均值 ≠ d 维余弦；与 FLTrust/PBFL 的"全维余弦"对比时口径不一 | 中（声明/对比公平性） | 改述指标名（"平均相位一致性"）或给两种指标的等价条件（各对范数均衡时近似）；实验同时报 d 维余弦对照 |

## 三、【步骤 3】数学算例闭环

### 3.1 厄米特恒等式算例（精确验证）

  梯度对 𝐠 = (1, 2) ⇒ 𝑧 = 1+2𝑗，𝜃 = atan2(2, 1) = 1.1071487 rad
  参考对 𝐠_ref = (1, 1) ⇒ 𝜃_ref = atan2(1, 1) = 0.7853982 rad
  厄米特路线：Re(𝑒^{𝑗𝜃}·𝑒^{−𝑗𝜃_ref}) = cos(𝜃 − 𝜃_ref) = cos(0.3217505) = 0.9486833
  明文 2 维余弦：⟨(1,2),(1,1)⟩/(√5·√2) = 3/√10 = 0.9486833
  ✅ **两值精确相等（2 维对即块级余弦），恒等式实证成立。**

### 3.2 打包容量算例

  实数梯度 (𝑔₁, 𝑔₂, 𝑔₃, 𝑔₄) = (1, 2, 3, 4) ⇒ 复向量 (1+2𝑗, 3+4𝑗)：2 个复槽装下 4 个实数 ✅（实数嵌入需 4 槽/浪费虚部）。

### 3.3 免重缩放噪声界算例

  Δ = 2⁴⁰、𝑀 = 2¹⁵、𝜂_bound = 2Δ·10⁻⁸ ⇒ 𝜀_enc ≈ √(𝑀/2)·(1/(2Δ) + 2·10⁻⁸) ≈ 128·2.0e-8 ≈ 2.6e-6（相对梯度尺度 1e-2 可忽略）✅ 数值精度声明"亚 10⁻⁸ 相对误差"在该参数下成立。

### 3.4 P1 反例（承诺检验）

同方案 1 算例：𝑠 = 4+2𝑋、𝑐₁ = 1+𝑋、𝑏 = 2+6𝑋，𝑧 = 3：
  𝑏(3) = 20；𝑠(3)·𝑐₁(3) = 40 (mod 97) ⇒ 20 ≢ 40 ❌ 诚实份额被拒（复现 P1）。

## 五、【步骤 5】鲁棒性功能（HermitianCosFilter）单独深检

### 5.1 介绍

用单位模相位向量把"方向相似度"线性化：逐对相位余弦 → 均值 → MAD 阈值（𝒞̄ᵢ < Med − 2.5·MAD 剔除）→ 归一权重 𝐴ᵢ 线性聚合。

### 5.2 闭环推导（展开）

1. 恒等式：Re(𝑤ᵢ·𝑤̄_ref) = cos(𝜃ᵢ−𝜃_ref) ✅（3.1 实证）。
2. 免非线性：无除法/开方/密文乘 ⇒ 噪声线性 ✅。
3. MAD 阈值：崩溃点 50% ✅。
4. 对方向投毒（sign-flip、角度偏置）：相位差 ≈ 𝜋 ⇒ cos ≈ −1 被剔 ✅；对幅值投毒：相位不变 ⇒ **本模块不防幅值攻击**（需并用范数过滤——方案未写 ⚠️ P6（中））。

### 5.3 模块算例

  三机相位差 (0.1, 0.2, 2.8) rad ⇒ cos = (0.995, 0.980, −0.942)：Med = 0.980、MAD = Median(0.015, 0, 1.922) = 0.015 ⇒ 阈值 = 0.980 − 2.5·0.015 = 0.943 ⇒ −0.942 被剔 ✅。
  幅值投毒（方向不变、范数×100）：相位余弦全 1.0 ⇒ 全部通过 ❌ 实证 P6。

### 5.4 模块问题与安全

- P6：补范数门（或与方案 1 距离过滤组合）。
- P3 参考污染：EMA 中位数参考。
- 语义（P2）：对 2 维对精确、对全维近似——报告指标口径。
- 隐私：打分经盲化协同解锁（同方案 1），𝒮_H 不见密文 ✅。
