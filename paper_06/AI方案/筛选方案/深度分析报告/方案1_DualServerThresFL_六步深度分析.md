### 1.2 创新点单独介绍

- **创新 1（总体）**：全程工作在原环 ℛₘ,𝑄，取消内层模数 𝑄′ 升维与 O(𝑁²) P2P 切片广播，终端严格 1 轮上传即走。
- **创新 2（鲁棒）**：CommitDistFilter——乘性盲化距离 + MAD 截尾，抽离至步骤 5。
- **创新 3（核心新原语）**：OneShotDualMask——双通道同维掩码 + 双总私钥焊接 + 多项式求值承诺防伪。
- **创新 4（理论）**：RLWE + 噪声淹没引理安全性证明与实验指标（4.2×/11.4×）。

### 1.3 主线闭环推导（全流程展开）

**（1）密钥与加密。** 无人机 𝑃ᵢ 用公钥加密明文梯度 𝑀ᵢ：

  𝑐ᵢ,₀ = 𝑝₀·𝑢ᵢ + Δ·𝑀ᵢ + 𝑒ᵢ,₀ (mod 𝑄)
  𝑐ᵢ,₁ = 𝑝₁·𝑢ᵢ + 𝑒ᵢ,₁ (mod 𝑄)

**（2）聚合与外层解密关系。** 良性集合 𝔘_benign 同态求和，令 𝑢 = ∑𝑢ᵢ、𝑒₀ = ∑𝑒ᵢ,₀、𝑒₁ = ∑𝑒ᵢ,₁、𝑀 = ∑𝑀ᵢ：

  𝑐₀ = ∑ 𝑐ᵢ,₀ = 𝑝₀·𝑢 + Δ·𝑀 + 𝑒₀ (mod 𝑄)
  𝑐₁ = ∑ 𝑐ᵢ,₁ = 𝑝₁·𝑢 + 𝑒₁ (mod 𝑄)

用 𝑆 组合（逐项展开，验证正确性）：

  𝑐₀ + 𝑐₁·𝑆
    = (−𝑎·𝑆 + 𝑒_𝑝𝑘)·𝑢 + Δ·𝑀 + 𝑒₀ + (𝑎·𝑢 + 𝑒₁)·𝑆
    = −𝑎·𝑆·𝑢 + 𝑒_𝑝𝑘·𝑢 + Δ·𝑀 + 𝑒₀ + 𝑎·𝑢·𝑆 + 𝑒₁·𝑆
    = Δ·𝑀 + (𝑒_𝑝𝑘·𝑢 + 𝑒₀ + 𝑒₁·𝑆)  (mod 𝑄)

  ✅ 消去 −𝑎·𝑆·𝑢 与 +𝑎·𝑢·𝑆（环乘法交换），得到 𝑐₀ + 𝑏 = Δ·𝑀 + 𝑒_𝐶𝑇，其中 𝑏 = 𝑐₁·𝑆，𝑒_𝐶𝑇 = 𝑒_𝑝𝑘·𝑢 + 𝑒₀ + 𝑒₁·𝑆。**本步正确。**

**（3）单轮双通道掩码。** 𝑃ᵢ 计算 𝑏ᵢ = 𝑐₁·𝑠ᵢ (mod 𝑄)，采样 𝑛ᵢ 与种子派生 𝑒𝑘ᵢ,₁、𝑒𝑘ᵢ,₂：

  𝑐′_{b,i,0} = (𝑎′·𝑒𝑘ᵢ,₁)·𝑢′ + 𝑏ᵢ (mod 𝑄)
  𝑐′_{n,i,0} = (𝑎′·𝑒𝑘ᵢ,₂)·𝑢′ + 𝑛ᵢ (mod 𝑄)

**（4）非对称线性组合。** 通道 1 乘拉格朗日系数、通道 2 系数为 1：

  𝐶′ₐₗₗ,₀ = ∑ᵢ∈𝒯 ( 𝐿ᵢ^(𝒯)·𝑐′_{b,i,0} + 𝑐′_{n,i,0} )  (mod 𝑄)

逐项展开：

  = ∑ᵢ∈𝒯 𝐿ᵢ^(𝒯)·(𝑎′·𝑒𝑘ᵢ,₁)·𝑢′ + ∑ᵢ∈𝒯 𝐿ᵢ^(𝒯)·𝑏ᵢ + ∑ᵢ∈𝒯 (𝑎′·𝑒𝑘ᵢ,₂)·𝑢′ + ∑ᵢ∈𝒯 𝑛ᵢ
  = (𝑎′·𝑢′)·(∑ᵢ∈𝒯 𝐿ᵢ^(𝒯)·𝑒𝑘ᵢ,₁) + (𝑎′·𝑢′)·(∑ᵢ∈𝒯 𝑒𝑘ᵢ,₂) + 𝑐₁·(∑ᵢ∈𝒯 𝐿ᵢ^(𝒯)·𝑠ᵢ) + ∑ᵢ∈𝒯 𝑛ᵢ
  = (𝑎′·𝑢′)·𝑆₁ + (𝑎′·𝑢′)·𝑆₂ + 𝑐₁·𝑆 + 𝑁_sm   (其中 𝑁_sm = ∑ᵢ∈𝒯 𝑛ᵢ)
  = (𝑎′·𝑢′)·(𝑆₁ + 𝑆₂) + 𝑐₁·𝑆 + 𝑁_sm  (mod 𝑄)

其中用到 ∑ᵢ∈𝒯 𝐿ᵢ^(𝒯)·𝑏ᵢ = ∑ᵢ∈𝒯 𝐿ᵢ^(𝒯)·𝑐₁·𝑠ᵢ = 𝑐₁·∑ᵢ∈𝒯 𝐿ᵢ^(𝒯)𝑠ᵢ = 𝑐₁·𝑆。**✅ 本步正确。**

**（5）一步消元。** 𝐶′ₐₗₗ,₁ = −𝑎′·𝑢′，𝑑𝑘 = 𝑆₁+𝑆₂：

  𝑏′ = 𝐶′ₐₗₗ,₀ + 𝐶′ₐₗₗ,₁·𝑑𝑘
     = (𝑎′·𝑢′)(𝑆₁+𝑆₂) + 𝑐₁·𝑆 + 𝑁_sm + (−𝑎′·𝑢′)(𝑆₁+𝑆₂)
     = 𝑐₁·𝑆 + 𝑁_sm  (mod 𝑄)   ✅ 掩码项完全消去。

**（6）还原明文。**

  𝑚′ = 𝑐₀ + 𝑏′ = Δ·𝑀 + 𝑒_𝐶𝑇 + 𝑁_sm (mod 𝑄)
  𝑀 = ⌊𝑚′/Δ⌉ (mod 𝑃)   条件：‖𝑒_𝐶𝑇 + 𝑁_sm‖∞ < Δ/2

噪声淹没条件（方案原文表述）：‖𝑒_𝐶𝑇‖∞ / 𝐵_sm ∈ negl(λ)，即混淆噪声远大于密文固有噪声，✅ 方向正确；同时须满足 |𝒯|·𝐵_sm + ‖𝑒_𝐶𝑇‖∞ < Δ/2，两侧约束构成可行窗口（原文未显式写出第二侧，属表述缺失而非错误）。

**（7）承诺检验等式（创新 3 的核心）——发现严重问题 ❌。**

原文检验式：

  𝑔^(𝑐′_{b,i,0}(𝑧_cₕₖ)) ≟ 𝑀_{i,1} · (𝑉𝐾ᵢ)^(𝑐₁(𝑧_cₕₖ))

右端指数为 (𝑎′·𝑒𝑘ᵢ,₁)·𝑢′ 在 𝑧_cₕₖ 处的求值 + 𝑠ᵢ(𝑧_cₕₖ)·𝑐₁(𝑧_cₕₖ)；左端指数为掩码求值 + 𝑏ᵢ(𝑧_cₕₖ)。等式成立要求：

  𝑏ᵢ(𝑧_cₕₖ) ≡ 𝑠ᵢ(𝑧_cₕₖ) · 𝑐₁(𝑧_cₕₖ)  (mod 𝑄)

但诚实客户端算的是商环乘积 𝑏ᵢ = 𝑐₁·𝑠ᵢ ∈ ℛₘ,𝑞（先乘后对 𝑋^𝑀+1 约化）。设多项式带余除法 𝑐₁(𝑋)·𝑠ᵢ(𝑋) = 𝑞(𝑋)·(𝑋^𝑀+1) + 𝑟(𝑋)，其中 𝑟 = 𝑏ᵢ，则：

  𝑏ᵢ(𝑧) = 𝑐₁(𝑧)·𝑠ᵢ(𝑧) − 𝑞(𝑧)·(𝑧^𝑀 + 1)

因此检验式成立 ⟺ 𝑞(𝑧)·(𝑧^𝑀+1) ≡ 0 (mod 𝑄)。对随机挑战点 𝑧_cₕₖ ∈ ℤ_𝑄^*，一般 𝑧^𝑀+1 ≢ 0，于是**诚实份额也会使检验失配**——承诺机制在原文设定下不可用，这是闭环推导的**致命断点**（数学上，"商环中先乘后约化再求值" ≠ "分别求值再相乘"，除非求值点是 𝑋^𝑀+1 的根）。

  𝑔^(𝑐′_{b,i,0}(𝑧)) = 𝑔^((𝑎′𝑒𝑘ᵢ,₁𝑢′)(𝑧) + 𝑏ᵢ(𝑧)) = 𝑀_{i,1} · 𝑔^(𝑠ᵢ(𝑧)·𝑐₁(𝑧)) = 𝑀_{i,1}·(𝑉𝐾ᵢ)^(𝑐₁(𝑧))  ✅

## 三、【步骤 3】数学算例闭环演算（微型环实例）

取 𝑄 = 97、𝑃 = 17、Δ = ⌊97/17⌋ = 5，环 ℛ = ℤ₉₇[𝑋]/(𝑋²+1)（𝑀=2）。密钥：𝑆 = 3+2𝑋，𝑎 = 1+𝑋，𝑒_𝑝𝑘 = 1：

  𝑝₀ = −𝑎·𝑆 + 𝑒_𝑝𝑘 = −(1+𝑋)(3+2𝑋) + 1 = −(3+5𝑋+2𝑋²) + 1
     = −(3+5𝑋−2) + 1 = −(1+5𝑋) + 1 = −5𝑋   (mod 97)   → 𝑝₀ = 92𝑋
  𝑝₁ = 1+𝑋

**加密**（消息 𝑀 = 4，𝑢 = 1，𝑒₀ = 𝑒₁ = 0）：

  𝑐₀ = 𝑝₀·1 + 5·4 + 0 = −5𝑋 + 20 = 20 + 92𝑋
  𝑐₁ = 1+𝑋

**验证外层关系**：𝑐₀ + 𝑐₁·𝑆 = 20−5𝑋 + (1+𝑋)(3+2𝑋) = 20−5𝑋 + (3+5𝑋−2) = 20−5𝑋+1+5𝑋 = 21
  而 Δ·𝑀 + 𝑒_𝑝𝑘·𝑢 = 20 + 1 = 21 ✅

**Shamir 份额**（𝑇=2，𝑁=2，𝐹(𝑋) = 𝑆 + 𝑋，𝛼₁=1、𝛼₂=2）：
  𝑠₁ = 𝐹(1) = 4+2𝑋，𝑠₂ = 𝐹(2) = 5+2𝑋
  𝐿₁ = 2/(2−1) = 2，𝐿₂ = 1/(1−2) = −1 ≡ 96
  校验：2·𝑠₁ − 𝑠₂ = (8+4𝑋) − (5+2𝑋) = 3+2𝑋 = 𝑆 ✅

**份额**：𝑏₁ = 𝑐₁·𝑠₁ = (1+𝑋)(4+2𝑋) = 4+6𝑋+2𝑋² = 2+6𝑋
         𝑏₂ = 𝑐₁·𝑠₂ = (1+𝑋)(5+2𝑋) = 5+7𝑋+2𝑋² = 3+7𝑋
  校验 ∑𝐿ᵢ𝑏ᵢ = 2(2+6𝑋) − (3+7X) = 4+12𝑋−3−7𝑋 = 1+5𝑋；而 𝑐₁·𝑆 = (1+𝑋)(3+2𝑋) = 1+5𝑋 ✅

**掩码**（取 𝑎′ = 𝑢′ = 1，则 (𝑎′·𝑒𝑘)·𝑢′ = 𝑒𝑘；𝑒𝑘₁,₁ = 7+3𝑋，𝑒𝑘₁,₂ = 4+𝑋，𝑒𝑘₂,₁ = 8+𝑋，𝑒𝑘₂,₂ = 2+5𝑋；𝑛₁ = 2，𝑛₂ = −1）：

  𝑐′_{b,1,0} = (7+3𝑋) + (2+6𝑋) = 9+9𝑋     𝑐′_{n,1,0} = (4+𝑋) + 2 = 6+𝑋
  𝑐′_{b,2,0} = (8+𝑋) + (3+7𝑋) = 11+8𝑋      𝑐′_{n,2,0} = (2+5𝑋) − 1 = 1+5𝑋

**组合**：
  𝐶′ₐₗₗ,₀ = 2·(9+9𝑋) + (6+𝑋) + (−1)·(11+8𝑋) + (1+5𝑋)
          = (18+18𝑋) + (6+𝑋) − (11+8𝑋) + (1+5𝑋) = 14 + 16𝑋  (mod 97)

**双总私钥**：
  𝑆₁ = 2·(7+3𝑋) − (8+𝑋) = 6+5𝑋
  𝑆₂ = (4+𝑋) + (2+5𝑋) = 6+6𝑋
  𝑑𝑘 = 12+11𝑋

**消元**（𝐶′ₐₗₗ,₁ = −1）：
  𝑏′ = (14+16𝑋) + (−1)·(12+11𝑋) = 2+5𝑋
  对照 𝑐₁·𝑆 + ∑𝑛ᵢ = (1+5𝑋) + 1 = 2+5𝑋 ✅✅ 完全吻合。

**还原**：𝑚′ = 𝑐₀ + 𝑏′ = (20−5𝑋) + (2+5𝑋) = 22；⌊22/5⌉ = 4.4 → **4 = 𝑀** ✅

**承诺检验 bug 的数值演示（P1）**：设 𝑠ᵢ(𝑋) = 4+2𝑋、𝑐₁(𝑋) = 1+𝑋，商环乘积 𝑏 = 2+6𝑋（𝑋² ≡ −1 已约化）。取 𝑧 = 3（不满足 𝑧² ≡ −1，因 3²=9 ≢ 96）：
  - 左端指数 𝑏(3) = 2+18 = 20
  - 右端指数 𝑠(3)·𝑐₁(3) = (4+6)·(1+3) = 10·4 = 40 ≢ 20 (mod 97)
  → 诚实份额检验失败 ✅ 复现 P1。
  修复：取 𝑧 = 10（10² = 100 ≡ 3 … 不满足）；改取 𝑧 满足 𝑧² ≡ 96：𝑧 = 31（31² = 961 = 97·9+83 …）。对 𝑀=2、𝑄=97，解 𝑧² ≡ 96：𝑧 = 49（49² = 2401 = 97·24+73 …不成立）。可见"找 𝑧^𝑀 ≡ −1 的点"需 𝑄 ≡ 1 (mod 2𝑀) 使 −1 为二次剩余且 𝑋^𝑀+1 有根；此时取 𝑧 = 𝑟 即可。工程上更稳妥的修复是 P1-②（系数向量内积承诺）。

**结论：主链算例闭环通过；承诺子模块算例复现致命 bug。**

## 五、【步骤 5】鲁棒性功能（CommitDistFilter）单独深检

### 5.1 单独介绍

功能：在门限解密**之前**，在密态下计算每架无人机梯度与群体中心的距离平方 𝐷ᵢ² = ‖𝑀ᵢ − 𝑀_mean‖²，经正实数乘性盲化后交 𝑆𝐻 解锁盲化标量，𝑆A 除以 𝛾ᵢ² 还原后按 MAD 阈值（𝐷ᵢ² > Med + 3·MAD）剔除拜占庭节点。

### 5.2 闭环推导（展开）

1. 中心密文：𝐶𝑇_mean = (1/|𝔘_up|)·∑ 𝐶𝑇ᵢ（明文系数乘密文，需 |𝔘_up| 在模下可逆或定点化）。
2. 差值与平方：𝑆𝐴 计算 𝐶𝑇ᵢ ⊖ 𝐶𝑇_mean，同态平方 + 重线性化 + log₂(𝑀/2) 次 EvalGal 旋转折半求和 ⇒ 第 1 槽为 𝐷ᵢ² = ∑ᵤ(𝑀ᵢ[u] − 𝑀_mean[u])²。**✅ 语义正确（CKKS 槽内平方和恒等式）。**
3. 盲化：𝑆𝐴 采样 𝛾ᵢ > 0，乘密文得 ⌊⌊𝛾ᵢ²·𝐷ᵢ²⌋⌋，协同解锁得 𝑑̃ᵢ² = 𝛾ᵢ²·𝐷ᵢ²；𝑆𝐴 计算 𝐷ᵢ² = 𝑑̃ᵢ²/𝛾ᵢ²。**⚠️ 此处 𝑆𝐴 获得真实 𝐷ᵢ²——与创新声明矛盾（P2）。**
4. 截尾：Med、MAD(𝐷²) = Median(‖𝐷ᵢ² − Med‖)，锁定 𝔘_benign。**✅ 鲁棒统计正确（MAD 对 50% 以下污染有崩溃点 50%）。**

### 5.3 校验结论与模块级问题

- 平方和旋转的**噪声增长**：密文-密文乘法使噪声二次增长，必须 rescale；方案未给预算（P4）。
- "1/|𝔘_up|·∑𝐶𝑇ᵢ" 在 BFV 下不可直接做实数除法；应改为乘模逆 |𝔘_up|⁻¹ (mod 𝑃) 或只用"到加权中心"的差值（免去除法）。
- **盲化可比性 bug（P2 的形式化）**：若 𝛾ᵢ 各不相同，盲化值 𝛾ᵢ²𝐷ᵢ² 之间不可比，"𝑆𝐻 侧排序截尾"（原文初期表述）不成立；当前版本排序在 𝑆𝐴 去盲后进行，则隐私目标必须改写。修复（推荐）：**公共 𝛾**，阈值判断𝛾²𝐷ᵢ² ≤ Med(𝛾²𝐷²) + 3·MAD(𝛾²𝐷²) 与去盲后等价（𝛾² > 0 保序、MAD 同倍缩放），全程不显示 𝐷ᵢ²。

### 5.4 模块数值算例

3 架无人机，真实距离平方 𝐷² = (1.0, 1.2, 9.0)（第 3 架为投毒）。取公共 𝛾 = 2，则盲化值 (4.0, 4.8, 36.0)：
  Med = 4.8，MAD = Median(|4−4.8|, |4.8−4.8|, |36−4.8|) = Median(0.8, 0, 31.2) = 0.8
  阈值 = 4.8 + 3·0.8 = 7.2 ⇒ 仅 36.0 被剔除 ✅
用独立 𝛾ᵢ = (2, 3, 0.5)：盲化值 (4.0, 10.8, 2.25) ⇒ Med = 4.0、MAD = Median(0, 6.8, 1.75) = 1.75、阈值 = 9.25 ⇒ **全部通过、投毒者漏检** ❌ —— 实证了"独立盲化 + 盲化域比较"不可行，也说明独立盲化必须在去盲后比较（此时 𝑆𝐴 见真实距离，P2 成立）。

### 5.5 模块安全性

- 对 𝑆𝐻：盲化值 𝛾²𝐷² 在乘性未知因子下仅泄露序关系（公共 𝛾 时）或零信息（独立 𝛾 时）——建议在威胁模型写明"𝑆𝐻 可见排序"。
