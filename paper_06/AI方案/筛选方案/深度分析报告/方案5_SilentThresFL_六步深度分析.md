### 1.3 主线闭环推导（展开）——发现致命安全问题 ❌

**（1）静默多项式定义（原文主路径）：**

  𝐹_{m,1}^(𝑡)(𝑥) = PRPG(𝑡, 𝑘_{m,0}^(1)) + ∑_{ν=1}^{𝑇−1} PRPG(𝑡, 𝑘_{m,ν}^(1))·𝑥^ν  (mod 𝑄′)

即 𝐹(𝑥) = 𝑐₀^(𝑡) + ∑_{ν=1}^{𝑇−1} 𝑐_ν^(𝑡)·𝑥^ν，其中常数项 𝑐₀^(𝑡) = 𝑒𝑘_{m,1}^(𝑡) 由根种子生成、**系数 𝑐_ν^(𝑡)（ν≥1）由分发给全体同伴的种子生成**。

**（2）份额计算与安全性检验——致命断点：**

同伴 𝐿𝑈_μ 本地算份额：𝑒𝑘𝑆ℎ𝑎𝑟𝑒_{μ,m} = 𝐹(𝑥_μ) = 𝑐₀^(𝑡) + ∑_{ν=1}^{𝑇−1} 𝑐_ν^(𝑡)·𝑥_μ^ν。

由于 𝐿𝑈_μ **持有全部系数种子** {𝑘_{m,ν}}，它知道所有 𝑐_ν^(𝑡)（ν ≥ 1）。于是单个份额即给出：

  𝑐₀^(𝑡) = 𝑒𝑘𝑆ℎ𝑎𝑟𝑒_{μ,m} − ∑_{ν=1}^{𝑇−1} 𝑐_ν^(𝑡)·𝑥_μ^ν  ⇒ **任意 1 架领航 UAV 即可恢复临时密钥 𝑒𝑘_{m,1}^(𝑡)** ❌

同理 𝑒𝑘_{m,2}^(𝑡)。再结合组合密钥 dk = ∑ₘ(𝐿ₘ·𝑒𝑘_{m,1}+𝑒𝑘_{m,2}) 与加密份额密文，敌手（单 UAV 或 GBS+1 UAV）可伪造/解密任意份额——**门限 𝑇 形同虚设，定理 4.1 的"少于 𝑇 个点值完全隐藏常数项"与机制矛盾**（Shamir 的安全性前提是"多项式系数保密"，此处系数被公开分发）。

**（3）安全变体（原文括注"或在评估点 𝑥_μ 处的组合 PRF 种子"）：**

𝐿𝑈ₘ 向每个 𝐿𝑈_μ 发送一个点值种子 𝑠_{m→μ}，使 PRPG(𝑡, 𝑠_{m→μ}) = 𝐹^(𝑡)(𝑥_μ)（每轮派生该点的份额值，系数与常数项都不暴露）。此时：
  - 任意 𝑇 个点值可插值恢复常数项（Shamir 正确性 ✅）
  - 𝑇−1 个点值对常数项信息论隐藏 ✅（标准 Shamir）
  - 每轮零通信 ✅（种子一次分发）
**该变体才是安全的实现**；主公式路径（系数种子分发）不安全。

**（4）SilentKey 组合解密（在安全变体下）——闭环正确 ✅：**

  𝑏ₘ = [𝒞₁·skShareₘ]𝑄；𝐶𝑇_{s_m} = (𝐚·𝑒𝑘_{m,1} + 𝐞 + Δ′·𝑏ₘ, −𝐚)；𝐶𝑇_{n_m} = (𝐚·𝑒𝑘_{m,2} + 𝐞 + Δ′·𝑛ₘ, −𝐚)
  CT_all = (∑ₘ 𝐿ₘ·𝐶𝑇_{s_m}[0] + 𝐶𝑇_{n_m}[0], −𝐚)
  用 dk = ∑ₘ(𝐿ₘ·𝑒𝑘_{m,1}+𝑒𝑘_{m,2}) 解密 ⇒ 𝑏̃′ = 𝒞₁·𝑠𝑘 + ∑ₘ 𝑛ₘ ✅（噪声不乘 𝐿ₘ，无爆炸；与 ATASSES 同构，推导同方案 3-(5)，逐项展开无误）
  𝒯₁ ≠ 𝒯₂ 的两轮独立在线集合下插值仍成立（dkShare_μ 用 𝒯₁ 的 𝐿ₘ 组合、由 𝒯₂ 插值恢复）✅ 设计正确。

## 三、【步骤 3】数学算例闭环（P1 反例 + 修复验证 + 组合解密）

### 3.1 P1 反例：系数种子 ⇒ 单点份额即破

𝑇 = 2，𝐹(𝑥) = 𝑐₀ + 𝑐₁·𝑥；取 𝑐₀ = 5（= 𝑒𝑘_{m,1}），𝑐₁ = 3（由分发的系数种子派生，同伴已知），评估点 𝑥_μ = 2：
  份额 𝐹(2) = 5 + 3·2 = 11
  同伴计算 𝑐₀ = 11 − 3·2 = 5 = 𝑒𝑘_{m,1} ❌ **单点恢复临时密钥，门限失效。**

### 3.2 修复验证：点值种子变体

𝐿𝑈ₘ 本地保 𝑐₀ 种子与全部系数种子；仅向 𝐿𝑈_μ 发送 𝑠_{m→μ} 使 PRPG(𝑡, 𝑠_{m→μ}) = 𝐹^(𝑡)(𝑥_μ)（预计算一次"点值序列"种子）。设 𝐹(𝑥) = 5+3𝑥：
  𝐿𝑈₁ 拿到种子扩展得 𝐹(1) = 8；𝐿𝑈₂ 拿到种子扩展得 𝐹(2) = 11；𝑇=2 插值：𝑐₀ = 𝐹(1) + (𝐹(2)−𝐹(1))·(0−1)/(2−1) = 8 − 3 = 5 ✅
  任一单点（8 或 11）对 𝑐₀ 无信息（因为对方不知系数/斜率）✅ Shamir 语义恢复。

### 3.3 SilentKey 组合解密算例

沿用方案 1/3 数值（𝒞₁ = 1+𝑋、skShare₁ = 4+2𝑋、skShare₂ = 5+2𝑋、𝐿 = (2, −1)、𝑛₁ = 2、𝑛₂ = −1）：
  ∑𝐿ₘ𝑏ₘ = 1+5𝑋 = 𝒞₁·𝑠𝑘 ✅；𝑏̃′ = 1+5𝑋 + 1 = 2+5𝑋；𝒞₀ = 20−5𝑋 ⇒ ⌊22/5⌉ = 4 ✅ 闭环通过。

### 3.4 EigenFilter 算例（2 维、4 子群）

偏差向量：𝐠̄₁ = (1, 0)、𝐠̄₂ = (0.9, 0.1)（良性）；𝐠̄₃ = 𝐠̄₄ = (0.6, 0.8)（共谋投毒，范数 ≈1 正常）。𝐯₀ = (1, 0)：
  𝛼₁ = 1.0、𝛼₂ = 0.9、𝛼₃ = 0.6、𝛼₄ = 0.6
  𝐯₁ = 1.0·(1,0) + 0.9·(0.9,0.1) + 0.6·(0.6,0.8) + 0.6·(0.6,0.8) = (2.53, 1.05)
  𝐯_eig = 𝐯₁/‖𝐯₁‖ = (0.923, 0.383)
  投影能量：𝜁₁ = (0.923)² = 0.852、𝜁₂ = (0.9·0.923+0.1·0.383)² = (0.869)² = 0.755、𝜁₃ = 𝜁₄ = (0.6·0.923+0.8·0.383)² = (0.860)² = 0.740
  ——单步幂法受良性方差主导，攻击方向未显形 ⇒ 需第二步幂迭代或谱隙条件（P2/P5 实证：单步在本例**未能**凸显投毒方向；两步：𝐯₂ = ∑⟨𝐠̄,𝐯₁⟩𝐠̄ ≈ (…)，方向进一步向最大方差特征向量旋转）。
  结论：**"两步"并非修辞，是检测力需求**；公式应补第二步。

## 五、【步骤 5】鲁棒性功能（EigenFilter）单独深检

### 5.1 介绍

对中心化偏差密文执行幂迭代提取协方差 𝚺 = (1/𝑀)∑𝐠̄𝐠̄ᵀ 的第一主特征方向 𝐯_eig，计算各子群投影能量 𝜁ₘ = ⟨𝐠̄ₘ, 𝐯_eig⟩²，MAD 阈值（𝜁ₘ > Med(𝜁)+3·MAD(𝜁)）剔除共谋投毒簇。

### 5.2 闭环推导（展开）

1. 中心化：⌊⌊𝐠̄ₘ⌋⌋ = ⌊⌊𝐠ₘ⌋⌋ ⊖ (1/𝑀)·⊕⌊⌊𝐠ₘ⌋⌋ ✅。
2. 幂迭代（一步）：𝐯₁ = ∑ₘ 𝛼ₘ·𝐠̄ₘ，其中 𝛼ₘ = ⟨𝐠̄ₘ, 𝐯₀⟩；则 𝐯₁ = ∑𝐦 𝐠̄ₘ𝐠̄ₘᵀ·𝐯₀ = 𝚺·𝐯₀（差常数 𝑀）✅ 数学正确。
3. 两步（应补）：𝐯₂ = √𝚺·𝐯₁ ⇒ 逼近 𝐯_eig；收敛率 (𝜆₂/𝜆₁)²ᵏ。
4. 投影能量：𝜁ₘ = ⟨𝐠̄ₘ, 𝐯_eig⟩² ≥ 0；MAD 崩溃点 50% ✅。
5. 谱分离（定理 4.2）：恶意共谋沿 𝐮_atk 排列 ⇒ 𝚺 的 𝜆₁ 沿 𝐮_atk，条件 𝛾𝜎_atk² > 𝜆_max(Σ_benign) 下检测成立 ✅（需 𝜆₁/𝜆₂ 谱隙，见 3.4 反例）。

## 六、【步骤 6】可验证性功能单独深检

### 6.1 介绍

巡检 UAV 生成 Pedersen 承诺 Com_{m,i} + BLS 签名；领航 UAV 累乘 Comₘ = ∏Com_{m,i}；GBS 输出 Com_glob = ∏_{m∈benign} Comₘ；客户端验证承诺与 BLS。

### 6.2 闭环推导

  Pedersen 同态：Com(𝑚₁)·Com(𝑚₂) = Com(𝑚₁+𝑚₂) ✅（同态累加绑定）
  Com_glob = ∏ Com_{m,i} = Com(∑𝑊… − 无权重场景 Com(∑𝐠)) ✅ 与聚合明文绑定
  BLS 聚合：σ_agg = ∏σᵢ，批量验证 ✅
  漏加检测：Com 只覆盖被累加者 ⇒ 漏加诚实更新时客户端可对照名单内自身承诺发现不一致 ✅（弱于 LHH 的"内容验证"，见下）

### 6.3 模块算例

Com 语义小例（指数形式）：Com(𝑚) = 𝑔^𝑚·ℎ^𝑟；Com(2)·Com(3) = 𝑔⁵·ℎ^(𝑟₁+𝑟₂) = Com(5) ✅ 同态。绑定性：若 GBS 输出 Com(5) 但下发 𝑚′=4 ⇒ 客户端无法从 Com(5) 与 4 直接比对（Pedersen 是承诺不是哈希！）——**⚠️ 缺口：Pedersen 承诺绑定值但客户端若不掌握开承诺对照，只能验证"聚合密文对应承诺"，需配合解密结果与承诺的一致性检验协议（开承诺或同态哈希）**。本方案仅写"核验 Com_glob 无误"，未给一致性检验式 ⇒ 验证链不完整（新问题 P6）。

### 6.4 模块问题与改进

- **P6（中）**：Pedersen 承诺需"解密值 vs 承诺"一致性检验（开承诺给全体 / 或加 LHH 通道）。建议：与方案 1–3 相同的 LHH(Δ_glob) ≟ Com 对应指数形式，或承诺打开后逐坐标核验。
