### 1.2 创新点

1. **OPM-Med**：部分解密前施加逐槽正仿射 (𝑎ᵤ𝑥+𝑏ᵤ) + 全局置换，𝑆₂ 在盲化域取中位数并重加密，𝑆₁ 密态逆仿射 ⇒ 双站均不见明文中位数。
2. **PB-LCTV**：1 次同态乘法得逐槽乘积 + 分区零迹掩码，𝑆₂ 分层求和消去零迹项，𝑆₁ 去均值得全部 𝐿 层余弦；分段软评分 ρ（零点连续常数 𝑐* = 1 − ln(1.5) = 0.594535）。
3. **可验证加权聚合**：T_glob = ∏(τᵢ)^(𝑊ᵢ)，客户端核验 LHH。
4. RLWE + DL 下的形式化安全证明。

### 1.3 主线闭环推导（展开）

**（1）双陷阱门加密。** 𝑔ᵢ、𝑔̂ᵢ 分别加密：

  𝑐ᵢ,₀ = 𝑣ᵢ·𝑏 + 𝑚ᵢ + 𝑒ᵢ,₀ (mod 𝑞₁)；𝑐ᵢ,₁ = 𝑣ᵢ·𝑎 + 𝑒ᵢ,₁ (mod 𝑞₁)

解密关系（份额拆分）：ψ = 𝑐̃₀ + 𝑐̃₁·𝑠₁ + 𝑒^(flood)；补 𝑠₂ 后 𝑐̃₀ + 𝑐̃₁·(𝑠₁+𝑠₂) = 明文项 + 噪声。**✅ 线性正确。**

**（2）OPM-Med 保序性。** 正仿射 𝑓ᵤ(𝑥) = 𝑎ᵤ𝑥 + 𝑏ᵤ（𝑎ᵤ > 0）严格单调，故

  Median({𝑎ᵤ𝑥ᵢ+𝑏ᵤ}ᵢ) = 𝑎ᵤ·Median({𝑥ᵢ}) + 𝑏ᵤ  ✅（保序统计量不变原理）

**（3）仿射盲化密文与部分解密。** 𝑆₁ 计算：

  𝑐̃ᵢ,₀ = 𝐴_aff·𝑐ᵢ,₀ + 𝐵_aff (mod 𝑞₁)，𝑐̃ᵢ,₁ = 𝐴_aff·𝑐ᵢ,₁ (mod 𝑞₁)
  ψᵢ = 𝑐̃ᵢ,₀ + 𝑐̃ᵢ,₁·𝑠₁ + 𝑒ᵢ^(flood) (mod 𝑞₁)

（R-02：加小高斯防止 𝑆₂ 由 (𝑐̃ᵢ,₁, ψᵢ−𝑐̃ᵢ,₀) = (𝑐̃ᵢ,₁, 𝑐̃ᵢ,₁·𝑠₁) 的无误差 RLWE 样本解出 𝑠₁。**✅ 这个担忧数学上成立：无噪声样本 (𝑎, 𝑎·𝑠) 可线性解出 𝑠；加噪后归约到 RLWE 困难性，正确。**）

**（4）𝑆₂ 完成解密。** 𝐷ᵢ = ⌊Δ⁻¹·(ψᵢ + 𝑐̃ᵢ,₁·𝑠₂)⌉ (mod 𝑞₀)，槽值 ỹᵢ[u] = 𝑎ᵤ·𝑔ᵢ[u] + 𝑏ᵤ。**✅** 因为 𝑐̃ 明文 = 𝐴_aff·(𝑣𝑏+𝑚+𝑒)+𝐵_aff 对应 𝑎ᵤ·(Δ·𝑔ᵢ[u])+Δ·… 的编码（方案采用 𝐴_aff 编码为 Δ 标度、𝐵_aff 为 Δ² 标度以对齐乘积标度——CKKS 标度管理成立）。

**（5）盲化中位数与逆仿射。** ỹ_med[u] = Medianᵢ(ỹᵢ[u]) = 𝑎ᵤ·𝑔_med[u] + 𝑏ᵤ（由 (2)）。𝑆₂ 重加密 ⌊⌊ỹ_med⌋⌋，𝑆₁ 密态去盲：

  ⌊⌊𝑔_med⌋⌋ = Ecd(𝐚_aff⁻¹) ⊙ ( ⌊⌊ỹ_med⌋⌋ ⊖ Ecd(𝐛_aff) )  ✅（逐槽 (𝑦−𝑏ᵤ)/𝑎ᵤ = 𝑔_med[u]）

**（6）乘积盲化分层余弦。** 1 次同态乘法 ⌊⌊𝑔̂ᵢ⌋⌋ ⊗ ⌊⌊𝑔̂_med⌋⌋ ⇒ 逐槽乘积 𝑝ᵢ[u] = 𝑔̂ᵢ[u]·𝑔̂_med[u]；加掩码 𝑟[u] = 𝛿̄ℓ + 𝛿ℓ[u]，𝑆₂ 分层求和：

  𝜎̃_{i,ℓ} = ∑_{u∈Ωℓ} (𝑝ᵢ[u] + 𝛿̄ℓ + 𝛿ℓ[u])
          = ∑_{u∈Ωℓ} 𝑔̂ᵢ[u]·𝑔̂_med[u] + 𝑑ℓ·𝛿̄ℓ + ∑𝛿ℓ[u]
          = cos(𝑔̂ᵢ[Ωℓ], 𝑔̂_med[Ωℓ]) + 𝑑ℓ·𝛿̄ℓ      （零迹 ∑𝛿ℓ[u] = 0）

  𝜇_{i,ℓ} = 𝜎̃_{i,ℓ} − 𝑑ℓ·𝛿̄ℓ ✅ **闭环精确成立（逐项展开验证无误）。**

**（7）软评分连续性（自查 R-04）。** 𝜇̄ = 0 时：左支 ln(1+0.5·1) = ln(1.5) = 0.405465；右支 1² − 𝑐* = 1 − 0.594535 = 0.405465 ✅ **连续，方案已自洽（原 0.59 会导致 0.0045 断点，已修复）。**

**（8）加权聚合与验证。** 𝒞₀ = ∑𝑊ᵢ·𝑐ᵢ,₀、𝒞₁ = ∑𝑊ᵢ·𝑐ᵢ,₁；𝑃₁ = 𝒞₀+𝒞₁·𝑠₁+𝑒₁、𝑃₂ = 𝒞₁·𝑠₂+𝑒₂；客户端 𝑃₁+𝑃₂ = ∑𝑊ᵢ·(Δ·𝑔ᵢ) + (𝑒₁+𝑒₂) ⇒ 解码得 𝐺_sum = ∑𝑊ᵢ𝑔ᵢ。**✅ 线性正确。**

## 三、【步骤 3】数学算例闭环

### 3.1 OPM-Med 算例（3 客户端、1 槽位组）

真实槽值（第 𝑢 槽）：𝑔₁ = 1.0、𝑔₂ = 2.0、𝑔₃ = 5.0（𝑔₃ 为离群投毒）。𝑆₁ 采样 𝑎 = 2.0、𝑏 = 3.0：
  盲化值：ỹ = (2·1+3, 2·2+3, 2·5+3) = (5, 7, 13)
  𝑆₂ 取中位数：ỹ_med = 7
  𝑆₁ 去盲：(7 − 3)/2 = 2.0 = Median(1, 2, 5) ✅ 闭环正确。
差值防护演示：𝑆₂ 若相减 ỹ₁−ỹ₂ = −2 = 𝑎·(1−2)，仅知差值被 𝑎=2 缩放，不知真实差 −1 ✅（但排名 1<2<3 对 𝑆₂ 可见 —— P2）。

### 3.2 零迹掩码分层余弦算例（1 层、2 槽）

归一化内积真值 𝑝 = (0.5, −0.2)（层内积 = 0.3）。𝑆₁ 采样 𝛿̄ = 0.1、𝛿 = (0.05, −0.05)（零迹 ✅）：
  𝑆₂ 见槽值：(0.5+0.15, −0.2+0.05) = (0.65, −0.15)（单槽被掩码）
  层求和：0.65 + (−0.15) = 0.50 = 0.3 + 2·0.1 + 0 ✅
  𝑆₁ 去盲：0.50 − 2·0.1 = 0.30 = cos ✅ 闭环正确。

### 3.3 软评分连续性算例

  𝜇̄ = −0.4：左支 ln(1+0.5·0.6) = ln(1.3) = 0.262364
  𝜇̄ = +0.0：左支 ln(1.5) = 0.405465 = 右支 1 − 0.594535 ✅ 无缝
  𝜇̄ = +0.6：右支 (1.6)² − 0.594535 = 2.56 − 0.594535 = 1.965465

### 3.4 P1 验证域不匹配算例

取 Δ = 10、𝑊 = 3、𝑔 = 0.15：
  标签指数（整数域）：𝑊·⌊Δ·𝑔⌉ = 3·⌊1.5⌉ = 3·2 = 6
  客户端验证值：⌊Δ·𝑊·𝑔⌉ = ⌊4.5⌉ = 4
  6 ≠ 4 ⇒ T_glob = 𝑔⁶，LHH(𝐺_sum) = 𝑔⁴ ⇒ **诚实聚合被拒** ❌ 复现 P1。
  修复后统一整数域：𝐺_sum^int = 6，LHH = 𝑔⁶ = T_glob ✅。

## 四、【步骤 4】威胁模型与安全性分析检查

### 4.1 正确部分

3. **定理 2.2 的 LHH 防篡改归约（DL）正确**——但需 P1 的域修正后形式化才严密。

### 4.2 错误/缺失与解决

## 六、【步骤 6】可验证性功能单独深检

### 6.1 单独介绍

LHH 标签 τᵢ = LHH(⌊Δ·𝑔ᵢ⌉) 由客户端签名锁定并抄送双站；𝑆₂ 用收到的 τᵢ 计算 T_glob = ∏(τᵢ)^(𝑊ᵢ)；客户端合并解密后核验并更新。

### 6.2 闭环推导（展开）

  T_glob = ∏ᵢ (τᵢ)^(𝑊ᵢ) = ∏ᵢ (∏ᵤ 𝑔ᵤ^(⌊Δ𝑔ᵢ[u]⌉))^(𝑊ᵢ) = ∏ᵤ 𝑔ᵤ^(∑ᵢ 𝑊ᵢ⌊Δ𝑔ᵢ[u]⌉)

  LHH(⌊Δ·𝐺_sum⌉) = ∏ᵤ 𝑔ᵤ^(⌊Δ∑ᵢ𝑊ᵢ𝑔ᵢ[u]⌉)

两式相等 ⟺ ∑ᵢ 𝑊ᵢ⌊Δ𝑔ᵢ[u]⌉ = ⌊Δ∑ᵢ𝑊ᵢ𝑔ᵢ[u]⌉ ∀𝑢 —— **一般不成立（P1）**。修复（整数域定义）：

  令 𝑆_int[u] = ∑ᵢ 𝑊ᵢ·⌊Δ·𝑔ᵢ[u]⌉，验证 LHH(𝑆_int) ≟ T_glob，模型更新 Δ𝑤 = −𝜂·𝑆_int/(Δ·Δ_w)。✅ 此时恒等式精确成立。

防篡改健全性（修复后）：若 𝑆₁ 篡改 (𝑃₁+𝑃₂) 使解码结果对应指数向量 𝑒′ ≠ 𝑆_int，则 𝑔^(𝑒′) = T_glob 将给出生成元的离散对数关系，与 DL 矛盾 ✅（概率 1−1/𝑞_lhh）。

### 6.3 模块算例

𝑊 = (3, 2)，𝑔₁ = (0.15, −0.2)、𝑔₂ = (0.1, 0.4)，Δ = 10：
  ⌊Δ𝑔₁⌉ = (2, −2)、⌊Δ𝑔₂⌉ = (1, 4)
  𝑆_int = 3·(2, −2) + 2·(1, 4) = (8, 2) ⇒ T_glob = 𝑔ᵤ^(8+2) = 𝑔¹⁰
  实数和 𝐺_sum = 3·(0.15,−0.2)+2·(0.1,0.4) = (0.65, 0.2)；⌊Δ𝐺_sum⌉ = (6, 2) ⇒ LHH = 𝑔⁸ ≠ 𝑔¹⁰ ❌（P1 实证）；整数域验证 = 𝑔¹⁰ ✅。
