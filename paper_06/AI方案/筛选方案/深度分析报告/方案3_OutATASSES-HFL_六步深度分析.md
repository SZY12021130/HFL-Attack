## 一、【步骤 1】总体框架闭环公式推导与正确性校验

### 1.1 符号系统

| 符号 | 含义 |
| :--- | :--- |

| ℛₘ′,𝑃′、ℛₘ′,𝑄′、Δ′ | 辅助 BFV 内层环（𝑃′ = 𝑄）与缩放 Δ′ = ⌊𝑄′/𝑃′⌋ |

### 1.2 创新点

1. **OB-PackEnc**：终端零同态乘法（仅 1 次环系数减法盲化），代理 UAV 端簇内预聚合后全簇仅 1 次 RLWE 加密，𝑂(𝐾ₘ)→𝑂(1)。
2. **ATh-MedTrust**：ATASSES 加密份额近似恢复（无拉格朗日噪声爆炸）+ 密态中位数信任评估。
3. 终端不持有任何同态私钥（消除 FedOut 的单点失陷）。
4. 三层层次架构 + LHH/BLS 端到端验证。

### 1.3 主线闭环推导（展开）

**（1）终端盲化。** 传感器 𝑈_{m,i} 训练得 Δ𝑤_{m,i}，编码 𝑚̂_{m,i} = ⌊Δ·τ⁻¹(Δ𝑤_{m,i})⌉ ∈ ℛₘ,𝑞，用共享种子生成 𝑟_{m,i} = PRPG(𝑡, seed_{m,i})：

  𝑚̂′_{m,i} = [𝑚̂_{m,i} − 𝑟_{m,i}]_𝑄  ✅（一次减法，无乘法）

**（2）簇内预聚合与打包加密。** 代理 UAV：

  𝑀̂′ₘ = ∑ᵢ 𝑚̂′_{m,i} ≡ ∑ᵢ 𝑚̂_{m,i} − ∑ᵢ 𝑟_{m,i} (mod 𝑄)
  𝑐′_{m,0} = [𝑣ₘ·𝑝₀ + 𝑀̂′ₘ + 𝑒_{m,0}]_𝑄，𝑐′_{m,1} = [𝑣ₘ·𝑝₁ + 𝑒_{m,1}]_𝑄

**（3）GCS 去盲。** 𝑅ₘ = ∑ᵢ PRPG(𝑡, seed_{m,i})（GCS 与传感器共享种子）：

  𝑐_{m,0} = [𝑐′_{m,0} + 𝑅ₘ]_𝑄 = [𝑣ₘ·𝑝₀ + ∑ᵢ 𝑚̂_{m,i} + 𝑒_{m,0}]_𝑄，𝑐_{m,1} = 𝑐′_{m,1}

验证：𝑀̂′ₘ + 𝑅ₘ = ∑𝑚̂ − ∑𝑟 + ∑𝑟 = ∑𝑚̂_{m,i} ✅ **去盲精确，闭环正确。**
语义检查：(𝑐_{m,0}, 𝑐_{m,1}) 即簇级更新 Δₘ = ∑ᵢ Δ𝑤_{m,i} 的标准 RLWE 密文 ✅。

**（4）加权聚合。** 𝒞₀ = ∑ₘ 𝑊ₘ·𝑐_{m,0}、𝒞₁ = ∑ₘ 𝑊ₘ·𝑐_{m,1} (mod 𝑄)，对应明文 ∑𝑊ₘΔₘ ✅（明文-密文标量乘 + 加法，线性）。

**（5）ATASSES 两轮近似恢复（继承机制，展开校验）。** 在线代理 UAV 𝑃𝑈ₘ：

  𝑏ₘ = [𝒞₁·skShareₘ]_𝑄
  CT_{s,m,k} = ( [𝐚ₖ·𝑒𝑘_{m,1} + 𝐞_{m,1,k} + Δ′·𝑏_{m,k}]_{𝑄′}, −𝐚ₖ )
  CT_{n,m,k} = ( [𝐚ₖ·𝑒𝑘_{m,2} + 𝐞_{m,2,k} + Δ′·𝑛_{m,k}]_{𝑄′}, −𝐚ₖ )

组合（份额密文乘 𝐿ₘ、噪声密文系数 1）：

  CT_all,k = ( ∑ₘ (𝐿ₘ·CT_{s,m,k}[0] + CT_{n,m,k}[0]) mod 𝑄′, −𝐚ₖ )

用 dk = ∑ₘ(𝐿ₘ·𝑒𝑘_{m,1}+𝑒𝑘_{m,2}) 解密（BFV 线性密钥同态，逐项展开）：

  明文 = ∑ₘ 𝐿ₘ·(Δ′·𝑏_{m,k} + 𝐞残差) + ∑ₘ (Δ′·𝑛_{m,k} + 𝐞残差)
       = Δ′·( ∑ₘ 𝐿ₘ·𝑏_{m,k} + ∑ₘ 𝑛_{m,k} ) + 内层噪声

其中 ∑ₘ 𝐿ₘ·𝑏ₘ = ∑ₘ 𝐿ₘ·(𝒞₁·skShareₘ) = 𝒞₁·∑ₘ 𝐿ₘ skShareₘ = 𝒞₁·𝑠𝑘 ✅
  ⇒ 𝑏′ = 𝒞₁·𝑠𝑘 + ∑𝑛ₘ（模糊噪声界 ≤ 𝑇·𝐵_sm，**无拉格朗日放大**）✅
外层还原：⌊(𝒞₀ + 𝑏′)/Δ⌉ = ∑𝑊ₘΔₘ（条件 ‖𝑒_𝐶𝑇 + ∑𝑛ₘ‖∞ < Δ/2）✅ **主线闭环正确。**

## 三、【步骤 3】数学算例闭环

### 3.1 外包盲化算例（𝑄 = 97，环 ℤ₉₇[𝑋]/(𝑋²+1)）

传感器 1：𝑚̂₁ = 5+𝑋，𝑟₁ = 2+3𝑋 ⇒ 𝑚̂′₁ = (5+𝑋)−(2+3𝑋) = 3−2𝑋
传感器 2：𝑚̂′₂ = 7+4𝑋（其 𝑟₂ = 1+𝑋，𝑚̂₂ = 8+5𝑋）
簇内和：𝑀̂′ = (3−2𝑋)+(7+4𝑋) = 10+2𝑋
GCS 掩码和：𝑅 = 𝑟₁+𝑟₂ = (2+3𝑋)+(1+𝑋) = 3+4𝑋
去盲：10+2𝑋 + 3+4𝑋 = 13+6𝑋；对照 ∑𝑚̂ = (5+𝑋)+(8+5𝑋) = 13+6𝑋 ✅

### 3.2 ATASSES 组合解密算例（外层 𝑄 = 97，份额 𝑇=2/𝑀=2）

𝒞₁ = 1+𝑋，skShare₁ = 4+2𝑋、skShare₂ = 5+2𝑋，𝐿₁ = 2、𝐿₂ = −1（同方案 1 算例）：
  𝑏₁ = (1+𝑋)(4+2𝑋) = 2+6𝑋，𝑏₂ = (1+𝑋)(5+2𝑋) = 3+7𝑋
  ∑𝐿ₘ𝑏ₘ = 2(2+6𝑋)−(3+7𝑋) = 1+5𝑋 = 𝒞₁·𝑠𝑘 ✅（与方案 1 算例同构）
设噪声 𝑛₁ = 2、𝑛₂ = −1：𝑏′ = 1+5𝑋 + 1 = 2+5𝑋（内层 BFV 组合后得到的近似值）
取 𝒞₀ = 20−5𝑋（同方案 1 消息 𝑀 = 4）：⌊(𝒞₀+𝑏′)/Δ⌉ = ⌊22/5⌉ = 4 ✅

### 3.3 加权 LHH 的 P3 复现

𝑊₁ = 2、𝑊₂ = 3，簇标签指数（整数域）：2·⌊ΔΔ₁⌉ + 3·⌊ΔΔ₂⌉；若客户端按实数和 ⌊Δ(𝑊₁Δ₁+𝑊₂Δ₂)⌉ 校验，取 Δ = 10、Δ₁ = 0.15、Δ₂ = 0.1：
  整数域：2·2 + 3·1 = 7；实数域：⌊10·(0.3+0.3)⌉ = 6 ⇒ 不匹配 ❌（同方案 2 P1）

## 五、【步骤 5】鲁棒性功能单独深检

### 5.1 介绍

簇级鲁棒：对 𝑀 个簇的去盲密文提取逐坐标中位数基线 Δ_med，计算分层余弦 𝜇_{m,ℓ} = cos(Δₘ[Ωℓ], Δ_med[Ωℓ])，综合 𝜇̄ₘ = 0.5·Mean + 0.5·Min，分段软评分 → 𝑊ₘ。

### 5.2 闭环推导要点

1. 保序仿射中位数提取：同方案 2 步骤 5（恒等式 Median({𝑎𝑥ᵢ+𝑏}) = 𝑎·Median+b）✅；本方案在 GCS-PU 两方执行，隐私目标为"双站不见明文"。
2. 分层余弦恒等式：单位化后内积即余弦 ✅。
3. 软评分：ρ 的分段式（**0.59 版**）在 𝜇̄=0 处断点 0.0045 ❌（P2）；修复后单调连续 ✅。
4. 加权聚合同态线性 ✅。

### 5.3 模块算例

簇距离向量（单坐标）：(1.0, 1.2, 9.0) 与方案 1 相同：中位数 = 1.2 为基线；毒簇 9.0 与基线余弦（标量化为方向比）显著低 ⇒ 𝜌 降权。评分连续性：0.59 版 𝜇̄ = 0：左 0.405465、右 0.41 ⇒ 0.0045 断点 ❌；0.594535 版 0.405465 = 0.405465 ✅。

### 5.4 模块问题与安全

- 簇级样本数 𝑀 小 ⇒ 中位数统计力弱（𝐾=3 簇时中位数=中间簇），建议 MAD 阈值 + 簇内二次过滤。
- 𝑆₂ 类比角色（PU 群）可见保序盲化值 ⇒ 排名泄露（同方案 2 P2）。
- 防御实验需含 ALIE/IPM/层后门（2024-25 文献标准攻击集）。

## 六、【步骤 6】可验证性功能单独深检

### 6.1 介绍

传感器签 τ_{m,i} = LHH(Δ𝑤_{m,i})；PU 聚合 𝒯ₘ = ∏τ_{m,i}、σ_agg,m；GCS 合成 𝒯_glob = ∏(𝒯ₘ)^(𝑊ₘ)；传感器核验 BLS + LHH(Δ_glob) ≟ 𝒯_glob。

### 6.2 闭环推导（展开）

  LHH 同态性：∏_{m,i} τ_{m,i}^{𝑊ₘ} = 𝑔^(∑ₘ 𝑊ₘ ∑ᵢ ⌊ΔΔ𝑤_{m,i}⌉)
  客户端验证对象若为 ⌊Δ·∑𝑊ₘ∑Δ𝑤⌉ ⇒ 舍入不等（P3）。
  修复：验证 𝑆_int = ∑ₘ 𝑊ₘ·∑ᵢ⌊ΔΔ𝑤_{m,i}⌉（整数域），更新用 𝑆_int/Δ ✅。
