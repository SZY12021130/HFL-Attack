### 1.2 创新点

1. **幂次基密钥演进** 𝑎^(𝑡) = 𝑔^𝑡·𝑎₀：宣称使跨轮密文可"对齐"、掉线配平可用公开 𝑝𝑘ⱼ 直接乘 𝑔^𝑡 得零明文密文。
2. **滑动窗口轨迹筛查**：密态 EMA 轨迹范数/余弦，检测慢速漂移（单轮正常的渐进投毒）。
3. **误差补偿分块**（Top-ζ 活跃包 + 残差池）与一步本地解密（零握手）。
4. LHH + BLS 可验证。

### 1.3 主线闭环推导（展开）与逐项校验

**（1）加密。** 𝒞_{i,c}^(𝑡) = [−𝑎^(𝑡)·(𝑠ᵢ + 𝑠_{rx,i}^(𝑡)) + 𝑔̂_{i,c}^(𝑡) + 𝑒_{i,c}^(𝑡)]𝑞

**（2）配平密文构造（核心创新）——发现致命问题 ❌。**

  𝐶ⱼ^(pad,𝑡) = [𝑔^𝑡·𝑝𝑘ⱼ]𝑞 = [𝑔^𝑡·(−𝑎₀·𝑠ⱼ + 𝑒_{j,pk})]𝑞 = [−𝑎^(𝑡)·𝑠ⱼ + 𝑔^𝑡·𝑒_{j,pk}]𝑞

方案声称 𝑔^𝑡·𝑒_{j,pk} 是"温和误差"。**数学上不成立**：𝑔 是环元素，幂 𝑔^𝑡 (mod 𝑞) 的系数随 𝑡 增长/绕回而接近均匀分布（除非 𝑔 是单项式）。因此

  𝑒ⱼ^(pad,𝑡) = 𝑔^𝑡·𝑒_{j,pk} (mod 𝑞)

一般不再是小误差，而是全尺寸环元素。聚合后解密输出

  𝑀_glob = ∑𝑔̂_{i,c} + ∑𝑒_{i,c} + ∑_{j∈𝔘_miss} 𝑔^𝑡·𝑒_{j,pk}

最后一项将淹没 Δ-缩放的明文，**取整解码失败**。配平密文不是"零明文合法密文"（其噪声超出解密界）。**这是主线闭环的致命断点。**

**（3）跨轮对齐等式（形式正确、语义有问题 ⚠️）。**

  𝑔^𝜏·𝑎^(𝑡−𝜏) = 𝑔^𝜏·(𝑔^(𝑡−𝜏)·𝑎₀) = 𝑔^𝑡·𝑎₀ = 𝑎^(𝑡)  ✅ 纯代数正确

但把历史密文整体乘 𝑔^𝜏 时，**明文与噪声同时被 𝑔^𝜏 乘**：

  𝑔^𝜏·𝒞^(𝑡−𝜏) = [−𝑎^(𝑡)·(𝑠+𝑠_rx) + 𝑔^𝜏·𝑔̂ + 𝑔^𝜏·𝑒]𝑞

消息变成 𝑔^𝜏·𝑔̂（被环乘扭曲/移位），噪声变成 𝑔^𝜏·𝑒（同样非小量）。故"对齐后的密文"既不能直接相加求轨迹，也不能直接解密。方案中轨迹筛查实际用的是**独立评估密文** ⌊⌊𝐠⌋⌋（公钥 𝑝𝑘_eval），根本不需要主密文对齐——**对齐机制对所述用途是装饰性的**（⚠️ 创新点与用途错位）。

**（4）一步解密（在配平成立的前提下）——代数正确 ✅。**

  𝑀_glob = [𝒞_glob + 𝑎^(𝑡)·(𝑠_dec + 𝑆_rx^(𝑡))]𝑞
          = ∑_{i∈benign} 𝑔̂ᵢ + ∑𝑒ᵢ + ∑_{j∈miss}(𝑔^𝑡·𝑒_{j,pk})   （𝑠 项全部配平消去）

仅当 (2) 的噪声可控（即 𝑔 为单项式）时末项可忽略，此时解码正确。

**（5）残差补偿分块**：𝑉ᵢ = 𝑝ᵢΔ𝑤ᵢ + 𝑌ᵢ，未选中块回存残差池 ✅（标准误差补偿，无代数问题）。

## 三、【步骤 3】数学算例闭环（含 P1 反例与修复验证）

### 3.1 P1 反例：配平噪声爆炸（𝑞 = 97，环 ℤ₉₇[𝑋]/(𝑋²+1)，𝑔 = 1+𝑋，𝑒_{j,pk} = 1）

  𝑔¹ = 1+𝑋
  𝑔² = (1+𝑋)² = 1+2𝑋+𝑋² = 2𝑋
  𝑔³ = 2𝑋·(1+𝑋) = 2𝑋+2𝑋² = −2+2𝑋
  𝑔⁴ = (2𝑋)² = 4𝑋² = −4
  𝑔⁸ = (−4)² = 16
  𝑔¹⁶ = 16² = 256 ≡ 256 − 2·97 = 62 (mod 97)

配平噪声 ‖𝑔^𝑡·𝑒‖∞：𝑡=1 → 1；𝑡=4 → 4；𝑡=8 → 16；𝑡=16 → **62 ≫ Δ/2**（取 Δ = 5 时 Δ/2 = 2.5）。
取消息 𝑀 = 4、Δ = 5、无掉线时解密 𝑚′ = 20 + 噪声；含 1 个掉线节点、𝑡 = 16 时 𝑚′ = 20 + 62 = 82 ⇒ ⌊82/5⌉ = 16 ≢ 4 ❌ **解码失败，配平机制破坏正确性。**

### 3.2 修复验证：𝑔 = 𝑋（单项式）

  𝑔^𝑡 = 𝑋^𝑡；𝑋^𝑡·𝑒_{j,pk} 只是系数移位（若 𝑡 为偶数还要处理 𝑋^𝑁 = −1 的符号），范数保持 ‖𝑋^𝑡·𝑒‖∞ = ‖𝑒‖∞ ✅
  同时 𝑔^𝜏·𝑎^(𝑡−𝜏) = 𝑋^𝜏·𝑋^(𝑡−𝜏)·𝑎₀ = 𝑋^𝑡·𝑎₀ = 𝑎^(𝑡) ✅ 对齐式保持
  配平：𝐶ⱼ^pad = 𝑋^𝑡·𝑝𝑘ⱼ = −𝑋^t·𝑎₀𝑠ⱼ + 𝑋^t·𝑒_{j,pk} = −𝑎^(𝑡)𝑠ⱼ + 小噪声 ✅ **修复后闭环成立。**
  注意事项：此时"历史密文乘 𝑔^𝜏"等于槽轮换，明文被同步轮换——若要保留对齐用途，编码需做轮换不变设计（或删去对齐宣称，见 P2）。

### 3.3 一步解密正例（修复后）

沿用方案 1 算例参数（𝑞 = 97、Δ = 5、𝑆 = 3+2𝑋、𝑠₁ = 4+2𝑋、𝑠₂ = 5+2𝑋、𝑠_dec = 𝑆，𝐶_glob = 20−5𝑋+𝑏 项已配平）：解密 𝑀_glob = [𝒞_glob + 𝑎^(𝑡)·(𝑠_dec + 𝑆_rx)] = 20 + 小噪声 ⇒ ⌊22/5⌉ = 4 ✅。

### 3.4 P3 反例：单恶意客户端 + GBS 解密聚合

𝐵_rx 全网共享 ⇒ 恶意 𝑈ₖ 知道 ∀𝑖 的 𝑠_{rx,i}^(𝑡)；又知 𝑠_dec。于是
  𝑆_rx^(𝑡) = ∑_{i∈benign} 𝑠_{rx,i}^(𝑡) 可算，𝒞_glob + 𝑎^(𝑡)(𝑠_dec + 𝑆_rx^(𝑡)) = 全局明文 ✅ 可解
⇒ 定理 1.1 的"≤ 𝐾−2 合谋不能解聚合"不成立（虽然聚合明文本就向 UAV 广播，机密性目标应改写）。个体密文 𝒞_{i,c} 仍需 𝑠ᵢ（RLWE 保护）✅。

## 五、【步骤 5】鲁棒性功能（滑动窗口轨迹筛查）单独深检

### 5.1 介绍

对每架在线无人机在评估密文域构造 EMA 轨迹 𝐒_{i,c}^(𝑡) = ∑_{𝜏=0}^{𝜔−1} 𝜆𝜏·𝐠_{i,c}^(𝑡−𝜏)，同态计算 ‖𝐒‖₂² 与对全局历史基线的余弦 cos(𝐒_{i,c}^(𝑡), 𝐒_glob,c^(𝑡−1))；单轮范数 > Γ_norm 或轨迹余弦 < θ_traj 者剔除。

### 5.2 闭环推导

1. EMA 线性：⌊⌊𝐒⌋⌋ = ⊕𝜏 𝜆𝜏·⌊⌊𝐠^(𝑡−𝜏)⌋⌋ ✅（纯线性，密态可行）。
2. 范数：‖𝐒‖² = ⟨𝐒,𝐒⟩ 经 1 次乘法 + log₂𝐵_slot 次 EvalGal ✅。
